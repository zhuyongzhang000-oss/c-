# p1 | 编程题怎么写 | 数组题最常见的错，是把「数组能装多少」和「现在装了几个」搞混（见 ⑧）。

## gu | 骨架 | | 通用骨架
::code
// 冒泡：外层 n-1 趟，内层到 n-1-i
for (i = 0; i < n - 1; i++)
    for (j = 0; j < n - 1 - i; j++)
        if (a[j] > a[j + 1]) { t = a[j]; a[j] = a[j + 1]; a[j + 1] = t; }
::

## s1 | ① 冒泡排序 | ① | 冒泡：每一趟把最大的冒到最后
相邻两个比，前面的大就交换。一趟走完，最大的就到了最后；下一趟就不用再管最后那个，所以内层上界一趟比一趟少 1。
::table
 | 数组
开始 | 5 1 4 2 3
第 1 趟后 | 1 4 2 3 5
第 2 趟后 | 1 2 3 4 5
第 3、4 趟 | 不再变化
::
n 个数最多 {{n − 1}} 趟。要从大到小，把 `>` 改成 `<`。

交换要三句、借一个 t：`t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;`。只写 `a[j] = a[j + 1]; a[j + 1] = a[j];` 会让两个格子变成同一个数，道理和环01 ⑤ 一样。

## s2 | ② 选择排序 | ② | 选择排序：记住最小值的下标
每一趟找出剩下的里面最小的，和第 i 个交换：
::code
for (i = 0; i < n - 1; i++) {
    k = i;
    for (j = i + 1; j < n; j++)
        if (a[j] < a[k]) k = j;          // 记下标，不记值
    if (k != i) { t = a[i]; a[i] = a[k]; a[k] = t; }
}
::
为什么记下标 k 而不记值？{{只记住值，就不知道最小的在哪一格，没法交换}}。

## s3 | ③ 二分查找 | ③ | 二分查找：每次砍掉一半
**只能用在有序数组上**。每次看中间那个，要找的比它大就去右半边，比它小就去左半边。在 {1, 3, 5, 7, 9, 11, 13} 里找 11：
::table
left | right | mid | a[mid] | 下一步
0 | 6 | 3 | 7 | 7 < 11，left = 4
4 | 6 | 5 | 11 | 找到，下标 5
::
::code
left = 0; right = n - 1;
while (left <= right) {
    mid = (left + right) / 2;
    if (a[mid] == x) return mid;
    else if (a[mid] < x) left = mid + 1;
    else right = mid - 1;
}
return -1;                               // 找不到
::
三个容易错的地方：条件是 `left <= right`，**等号不能丢**（只剩一个数时也要比）；更新是 `mid + 1` 和 `mid - 1`，写成 `left = mid` 可能死循环；找到的是**下标**，题目问「第几个」要加 1。

## s4 | ④ 顺序查找 | ④ | 顺序查找：「没找到」放在循环外面判断
从头比到尾，找到就 break：
::code
for (k = 0; k < n; k++)
    if (a[k] == x) break;
if (k < n) 找到，下标 k;
else       没找到;                         // 循环正常走完，k 等于 n
::
~~在循环里面写 else 打印「没找到」~~，第一个不相等就会打出来。

## s5 | ⑤ 有序插入 | ⑤ | 有序插入：从右往左搬
先找到第一个不小于 x 的位置 pos，再把 pos 以后的数**从最后一个开始**往右挪一格，空出 pos：
::code
pos = 0;
while (pos < n && a[pos] < x) pos++;
for (i = n; i > pos; i--) a[i] = a[i - 1];    // 从右往左搬
a[pos] = x;
n++;
::
{1, 3, 5, 7, 9} 插入 4 得 {{1 3 4 5 7 9}}。

从左往右搬会怎样？a[pos+1] = a[pos] 之后，原来的 a[pos+1] 就被覆盖了，后面全是同一个数。

数组定义时要**多留一格**（`int a[6]` 装 5 个数），插入后有效长度 n 要加 1。

## s6 | ⑥ 合并两个有序数组 | ⑥ | 合并：两个游标，谁小取谁
::code
i = j = k = 0;
while (i < na && j < nb) {
    if (a[i] <= b[j]) c[k++] = a[i++];
    else              c[k++] = b[j++];
}
while (i < na) c[k++] = a[i++];    // 收尾：最容易漏
while (j < nb) c[k++] = b[j++];
::
{1, 4, 9} 和 {2, 3, 10, 12} 合并成 {{1 2 3 4 9 10 12}}。第一个 while 结束时，a 已经取完，b 还剩 {{10、12}}，靠最后一个 while 抄过去。

`c[k++] = a[i++];` 就是「把 a[i] 放进 c[k]，然后 k、i 各加 1」（回顾里那道题）。

## s7 | ⑦ 奇偶分组 | ⑦ | 分组：各用各的计数器
奇数放一个数组、偶数放另一个，每个数组有自己的「已经放了几个」：
::code
no = ne = 0;
for (i = 0; i < n; i++) {
    if (a[i] % 2 != 0) odd[no++] = a[i];
    else               even[ne++] = a[i];
}
::
{5, 8, 3, 6, 1, 2, 7} 分完：奇数 {{5 3 1 7}}，偶数 {{8 6 2}}。然后各自排序。

判奇数写 `a[i] % 2 != 0`，~~别写 `== 1`~~：负奇数 % 2 是 −1（环01 细5）。

## s8 | ⑧ 容量和有效长度 | ⑧ | 容量和有效长度要分开
`int a[100]` 的 100 是**容量**（最多装几个），n 才是**现在装了几个**。排序、查找、输出，循环上界都用 n。

写成 `for (i = 0; i < 100; i++)`，没放数据的格子也被算进去，读到的是不确定的值。

## d1 | 细1 长度必须是常量 | 细1 | 定义数组：长度必须是常量
::calc
int a[10]; ‖  ‖ 合法
int a[2 + 3]; ‖  ‖ 合法 ‖ 常量表达式
#define N 10 后 int a[N]; ‖  ‖ 合法 ‖ N 是符号常量
int n = 10; int a[n]; ‖  ‖ 不合法 ‖ 长度是变量（考试口径）
int a[]; ‖  ‖ 不合法 ‖ 没长度又没初值
int a[0..10]; 、int a(10); ‖  ‖ 不合法
::
> C99 允许「变长数组」`int a[n]`，gcc 能编译，但 VS 不支持，教材和考试都按不合法。
::exam
哪个数组定义是错的 => 用变量当长度的那个，如 `int N = 5; int a[N];` @ 配-6-5、配-6-7、配-6-8、配-6-9
::

## d2 | 细2 初始化 | 细2 | 初始化：给少了补 0，给多了报错
::calc
int a[5] = {1, 2}; ‖ → ‖ 1 2 0 0 0 ‖ 没给的补 0
int b[] = {7, 8, 9}; ‖ → ‖ 3 个元素 ‖ 长度由初值个数决定
int c[8] = {0}; ‖ → ‖ 全是 0 ‖ 求和、计数数组的标准写法
int d[4] = {1, 2, 3, 4, 5}; ‖ → ‖ 编译错 ‖ 初值太多，不是「多的忽略」
int e[5] = {, 1, 2}; ‖ → ‖ 编译错 ‖ 不能跳着给
::
::exam
`int a[8] = {0};` 和 `int a[] = {0};` => 都合法 @ 配-6-2
`int a[5] = {, 1, 2};` => 不合法 @ 配-6-4
`char c[2] = {"A", "B"};` => 不合法 @ 配-6-6
::

## d3 | 细3 下标从 0 开始 | 细3 | 下标从 0 到 长度 − 1
`int a[5];` 能用的是 a[0] 到 a[4]，**没有 a[5]**。

越界编译器不报错，运行时会改掉别的变量、或者让程序崩溃，结果不确定（未定义行为）。所以讲义不演示它。

下标必须是整数，可以是整数表达式（`a[i + 1]`、`a[m[0]]`），不能是 ~~`a[1.5]`~~。
::exam
关于下标的说法 => 下限不能是负数；`array[3.12]` 不合法 @ 配-6-3
::

## d4 | 细4 数组名不能赋值 | 细4 | 数组名不能被赋值
数组名代表数组的首地址，是一个**常量**。所以：
::calc
int a[5], b[5]; a = b; ‖  ‖ 编译错 ‖ 不能整体赋值
a = {1, 2, 3}; ‖  ‖ 编译错 ‖ 只有定义时能用 {} 初始化
if (a == b) ‖  ‖ 能编译，但比的是地址 ‖ 不是比内容
::
要复制只能一个一个来：`for (i = 0; i < 5; i++) a[i] = b[i];`。字符数组同理，`s = "abc";` 也不行（环08）。

## d5 | 细5 sizeof 数组 | 细5 | sizeof 数组名：整个数组的字节数
`int a[10];` 时 `sizeof(a)` 是 {{40}}，元素个数 = `sizeof(a) / sizeof(a[0])` = 10。`double d[4];` 时 `sizeof(d)` 是 {{32}}。

这个公式**只在定义数组的那个函数里有效**。数组传进别的函数就成了指针（细6），sizeof 得到的是指针的大小。所以函数参数总写成 `(int a[], int n)`，长度单独传。

## d6 | 细6 数组作参数 | 细6 | 数组作函数参数：传的是地址
::code
void f(int b[]) { b[0] = 99; }
// main 里：
int a[3] = {1, 2, 3};
f(a);                         // 之后 a[0] 是 99
::
函数拿到的是数组的首地址，改的就是原来那个数组。形参写 `int b[]`、`int b[100]` 都一样，其实都是指针。

调用写 `f(a)`，~~不写 `f(a[])`~~，~~也不写 `f(a[10])`~~（那是一个元素，还越界了）。

> 这是后面环09 的重点，这里先记住：**数组传进函数，函数能改原数组**。
::exam
形参 `float array[]` 实际是 => 指针变量 @ 配-6-35、配-6-36
`fun(b[11])` 这样调用 => 错误 @ 配-6-37
函数里 `b[i] *= 2`，回到主函数输出 => 数组已经变了 @ 配-6-38
::

## d7 | 细7 下标套下标 | 细7 | 下标里套下标：从里往外算
`int m[] = {5, 4, 3, 2, 1};`，`m[m[3]]` 先算 m[3] 是 2，再算 m[2] 是 {{3}}。

计数的经典写法：`c[s[i]]++`，数字 s[i] 出现一次，`c[s[i]]` 就加 1。s = {1, 2, 2, 3, 3, 3} 统计完，c[3] 是 {{3}}。
::exam
`m[m[0]]`（m[0] 是 5，长度 5）=> 越界 @ 配-6-10
`c[s[i]]++` 计数 @ 配-6-12
::

## d8 | 细8 原地逆序 | 细8 | 原地逆序：只走一半
第 i 个和第 n−1−i 个交换，**i 只走到 n/2**：
::calc
for (i = 0; i < n / 2; i++) 交换 ‖ → ‖ 5 4 3 2 1 ‖ 对
for (i = 0; i < n; i++) 交换 ‖ → ‖ 1 2 3 4 5 ‖ 前一半换过去，后一半又换回来
::
::exam
从大到小改成从小到大，选哪个循环 => `for (i = 0; i < n / 2; i++)` @ 配-6-13
::

## d9 | 细9 输入数组 | 细9 | 输入数组：&a[i] 或 a + i
`scanf("%d", &a[i])` 和 `scanf("%d", a + i)` 都对：`a + i` 就是第 i 个元素的地址（指针在环11 细讲）。

~~`scanf("%d", a[i])`~~ 少了 &（环01 细11）。
::exam
填空：读入数组元素 => `a + (i++)` 或 `&a[i++]` @ 配-6-26、配-6-27
::

## d10 | 细10 不初始化是垃圾值 | 细10 | 不初始化的数组里是什么
函数里的局部数组不初始化，里面是不确定的值；**全局数组、static 数组自动全是 0**。

求和、计数用的数组，一定写 `= {0}`：只写一个 0，其余全部补 0（细2）。
