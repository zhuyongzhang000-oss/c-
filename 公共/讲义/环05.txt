@summary 三角形、菱形、错位星号、杨辉三角。细节：putchar 和 puts、宽度对齐、每行 k 个换行、内外层用了同一个变量、字母图案。
@intro 图案题看着花，其实全是同一个套路：外层管第几行，内层管这一行打几个空格、几个字符。难的不是代码，是先在纸上把「第 i 行几个空格、几个星号」数清楚。

== recall
`x = 0; switch (2) { case 1: x++; case 2: x++; case 3: x++; }` 之后 x => 2（从 case 2 一路穿透到底） @ 环04 细6
`7 / 2 * 2` => 6 @ 环01 ①
`char c = 'a' + 1;` 用 %c 输出 => b @ 环02 细2
`for (i = 0; i < 5; i++);` 之后 i => 5 @ 环03 细8
==

# p1 | 编程题怎么写 | 外层一轮 = 一行。每一行：先打空格，再打字符，最后换行。

## gu | 骨架 | | 通用骨架
::code
for (i = 1; i <= n; i++) {                            // 第 i 行
    for (j = 1; j <= 空格数(i); j++) printf(" ");
    for (j = 1; j <= 字符数(i); j++) printf("*");
    printf("\n");                                     // 换行在内层循环外面
}
::

## s1 | ① 先列表找公式 | ① | 先在纸上列表，再找公式
n = 4 的金字塔，一行一行数：
::table
第 i 行 | 空格 | 星号
1 | 3 | 1
2 | 2 | 3
3 | 1 | 5
4 | 0 | 7
::
看出来：空格 = {{n − i}}，星号 = {{2i − 1}}。把这两个公式填进骨架的两个内层上界，就写完了：
::out
   *
  ***
 *****
*******
::
**所有图案题都先做这一步**，公式找对了，代码几乎不会错。

## s2 | ② 上界跟着 i 变 | ② | 内层的上界要跟着 i 变
内层上界写成常数，每行打的个数都一样，图案就成了矩形：
::code
for (i = 1; i <= 3; i++) {
    for (j = 1; j <= 5; j++) printf("*");     // 上界是常数 5
    printf("\n");
}
::
::outa
*****
*****
*****
::
三角形的每行个数不一样，所以上界里一定有 i。

## s3 | ③ 换行放在哪 | ③ | 换行放在内层循环外面
`printf("\n")` 要在内层循环**外面**、外层循环**里面**。放进内层，就成了一个星号一行：
::code
for (i = 1; i <= 2; i++)
    for (j = 1; j <= 3; j++) { printf("*"); printf("\n"); }
::
这段输出 {{6 行，每行一个 *}}。

## s4 | ④ 菱形 = 上半 + 下半 | ④ | 菱形：上半正着走，下半倒着走
菱形的下半就是上半倒过来。公式不用改，只要让 i 倒着走：
::code
for (i = 1; i <= n; i++)      { 空格 n-i 个；星号 2i-1 个；换行 }   // 上半
for (i = n - 1; i >= 1; i--)  { 空格 n-i 个；星号 2i-1 个；换行 }   // 下半
::
n = 3：
::outa
  *
 ***
*****
 ***
  *
::
下半从 **n − 1** 开始，不然中间最宽的那行会打两遍。

## s5 | ⑤ 星号之间有空格 | ⑤ | 星号之间有空格
图案里写成「* * * *」时，一个单位是「星号 + 空格」两格宽。行尾不想多一个空格，就在最后一个之前才打空格：
::code
for (j = 1; j <= 4; j++) {
    printf("*");
    if (j < 4) printf(" ");     // 最后一个星号后面不加空格
}
::
每行再错开几格，就是在前面多打几个空格：第 i 行（i 从 0 数）先打 i 个空格。三行的样子：
::outa
* * * *
 * * * *
  * * * *
::

## s6 | ⑥ 杨辉三角 | ⑥ | 杨辉三角：两边是 1，中间是左上加正上
用二维数组存（二维数组的规矩环07 细讲）：
::code
for (i = 0; i < n; i++) {
    a[i][0] = a[i][i] = 1;                            // 每行两端
    for (j = 1; j < i; j++)
        a[i][j] = a[i - 1][j - 1] + a[i - 1][j];      // 左上 + 正上
}
::
::outa
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
1 5 10 10 5 1
::
第 i 行只用 `a[i][0]` 到 `a[i][i]`。数和数之间一个空格、行首行尾不加，可以用 `printf(k ? " %d" : "%d", a[i][k])`（环03 细7 的条件运算符）。

## s7 | ⑦ 数字表格要对齐 | ⑦ | 数字表格：给宽度就对齐了
九九乘法表这类，给每个数一个固定宽度。`%-3d` 占 3 格、靠左（环01 细10）：
::code
for (i = 1; i <= 3; i++) {
    for (j = 1; j <= i; j++) printf("%d*%d=%-3d", j, i, i * j);
    printf("\n");
}
::
::out
1*1=1
1*2=2  2*2=4
1*3=3  2*3=6  3*3=9
::

## s8 | ⑧ 用 n = 1 测一次 | ⑧ | 写完用 n = 1 测一次
写之前画 n = 3 的样子数格子；写完拿 n = 1 测：金字塔应该只有一个 *，菱形也只有一个 *。最容易错的就是这个边界。

# p2 | 输出和循环变量的坑 | 每一节最后附了真题的问法，灰色小字是出处。

## d1 | 细1 putchar 和 puts | 细1 | putchar、puts、printf
- `putchar(c)`：输出**一个字符**。`putchar(65)` 输出 {{A}}，`putchar('0' + 5)` 输出 {{5}}。
- `puts(s)`：输出一个字符串，**自动加换行**。
- `printf`：最灵活，但不会自动换行。

~~`putchar("A")`~~ 错，要的是字符不是字符串；~~`putchar('ab')`~~ 里的 'ab' 本身就不合法（环02 细3）。
::exam
能输出字符 a 的 => `putchar(97)` @ 配-3-62
`for (i = 0; i < 5; i++) putchar('Z' - i);` => ZYXWV @ 配-3-64
::

## d2 | 细2 宽度对齐 | 细2 | %5d、%-5s：宽度和对齐
环01 细10 讲过数字，字符串和字符也一样。下面用 · 表示空格：
::calc
printf("%5d", 42) ‖ → ‖ «···42»
printf("%-5d", 42) ‖ → ‖ «42···»
printf("%5s", "ab") ‖ → ‖ «···ab»
printf("%-5s", "ab") ‖ → ‖ «ab···»
printf("%3c", 'x') ‖ → ‖ «··x»
printf("%2d", 12345) ‖ → ‖ «12345» ‖ 比宽度长，原样输出，不截断
::
::exam
`printf("%4d,%o,%x", 10, 10, 10);` => «··10,12,a» @ 配-3-6
::

## d3 | 细3 每行 k 个 | 细3 | 每行输出 k 个就换行
用下标或计数器取余：
::code
for (i = 0; i < 10; i++) {
    printf("%3d", i);
    if ((i + 1) % 4 == 0) printf("\n");     // 第 4、8 个后面换行
}
::
第二行是 {{4 5 6 7}}，第三行只有 {{8 9}}。

`(i + 1) % 4` 和 `i % 4` 差在哪：前者是「打完第 4 个之后换行」，后者是「打第 0、4、8 个之前换行」，所以要写在 printf 前面。
::exam
每行 8 个的填空 => `if (i % 8 == 0) printf("\n");`（写在 printf 之前） @ 配-4-34
::

## d4 | 细4 内外层同一个变量 | 细4 | 内外层用了同一个循环变量
::code
cnt = 0;
for (i = 1; i <= 3; i++)
    for (i = 1; i <= 2; i++) cnt++;     // 内层也用 i
::
想要 3 × 2 = 6 次，实际 {{2}} 次：内层结束时 i 是 3，外层 i++ 变成 4，外层立刻结束。

图案题内层一律用 j。

## d5 | 细5 循环体里改了循环变量 | 细5 | 循环体里又改了循环变量
读程序时，**每一处 `k++`、`++k` 都要算进去**，一轮里 k 可能被加好几次：
::code
for (k = 1; k <= 40; k++) {
    if (k++ % 5 == 0)
        if (++k % 8 == 0) printf("%d ", k);
}
::
输出 {{32}}。追踪时把「判断前的 k、判断后的 k、这一轮结束的 k」分三列写。
::exam
上面这段 => 32 @ 配-2-118
::

## d6 | 细6 字母图案 | 细6 | 字母图案：'A' + j 就是第 j 个字母
::code
for (i = 0; i < 4; i++) {
    for (j = 0; j <= i; j++) putchar('A' + j);
    putchar('\n');
}
::
::outa
A
AB
ABC
ABCD
::
::exam
i 是奇数输出小写、偶数输出大写 => AbCdEf @ 配-3-53
字符 '3' + i 的输出 @ 配-3-66
::

## d7 | 细7 嵌套次数 | 细7 | 嵌套循环执行几次
外层 m 次、内层 n 次，内层语句执行 m × n 次。有 continue 跳过的要减掉：
::code
cnt = 0;
for (i = 0; i < 2; i++)
    for (j = 0; j <= 3; j++) { if (j % 2 == 0) continue; cnt++; }
::
内层 j 取 0、1、2、3，只有 1、3 会数，所以 cnt = {{4}}。
::exam
嵌套循环后 x 的最终值 @ 配-5-52
for 后面带分号的嵌套循环 @ 配-5-54
::

## d8 | 细8 格式要一模一样 | 细8 | 行尾空格、换行：要有数格子的习惯
考试手写，行尾多一个空格、少一个换行一般不扣分；但这个仓库的测试是逐字比较的，所以题目会把格式写清楚。写图案题时养成习惯：每一行先数清楚有几个空格、几个字符。
