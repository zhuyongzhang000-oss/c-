# p1 | 编程题怎么写 | 枚举就是「全部试一遍」。写之前先回答：每个变量最小是几、最大是几？

## gu | 骨架 | | 通用骨架
::code
count = 0;
for (x = 0; x <= X的上限; x++)
    for (y = 0; y <= Y的上限; y++) {
        z = 由条件算出来;            // 能算出来的变量不再枚举
        if (z 合法 && 其他条件) { count++; 输出这一组; }
    }
::

## s1 | ① 先定范围 | ① | 先定每个变量的范围
范围用「全花在这一种上，最多几个」来定。100 元换 1、2、5 元：5 元最多 {{20}} 张，2 元最多 {{50}} 张，1 元最多 100 张。

范围要**带端点**：z 从 0 到 20，写 `z <= 20`。一张 5 元都不要，也是一种方案。

## s2 | ② 三层变两层 | ② | 能算出来的变量，不再枚举
x + 2y + 5z = 100，z 和 y 定了，x 就是 100 − 5z − 2y，不用再试。
::pair 三层：x、y、z 都试 | 两层：x 算出来
for (z = 0; z <= 20; z++)
  for (y = 0; y <= 50; y++)
    for (x = 0; x <= 100; x++)
      if (x + 2*y + 5*z == 100)
        count++;
---
for (z = 0; z <= 20; z++)
  for (y = 0; y <= (100 - 5*z) / 2; y++)
    count++;    // x = 100-5z-2y，一定 >= 0
::
两种都得 {{541}} 种方案。左边判断了 108171 次，右边只循环 541 次。题3 要求「只用两层循环」，就是这个意思。

## s3 | ③ 计数器放外面 | ③ | 计数器在所有循环外面清零
`count = 0` 写在**最外层循环前面**。写进循环里面，每一轮都被清零，最后只剩 0 或 1。

反过来，每一组方案自己用的临时量（比如算出来的 z），在循环里面算。

## s4 | ④ 整除陷阱 | ④ | 整除陷阱：先判断能不能整除
百钱百鸡：公鸡 5 元、母鸡 3 元、小鸡 1 元 3 只，100 元买 100 只。小鸡 z 只花 `z / 3` 元，可 `z / 3` 是整除（环01 ①）：z = 4 时 4 / 3 = 1，相当于 4 只小鸡只花了 1 元。
::code
z = 100 - x - y;
if (z % 3 == 0 && 5*x + 3*y + z/3 == 100) …    // 先判 z 能被 3 整除
::
判了 `z % 3 == 0` 得 {{4}} 种（对）；没判得 {{7}} 种，多出来的是小鸡「买了零头」。

## s5 | ⑤ 先输出每组再输出总数 | ⑤ | 每一组都输出，最后输出总数
`count++` 和 `printf` 放在同一个 if 里，一组一行，循环结束后再打印总数。拿 10 元换 1、2、5 元试一下（外层 z、内层 y，每行 x y z）：
::code
for (z = 0; z <= 10 / 5; z++)
    for (y = 0; y <= (10 - 5*z) / 2; y++) {
        x = 10 - 5*z - 2*y;
        printf("%d %d %d\n", x, y, z);
        count++;
    }
printf("%d\n", count);
::
前两行是 «10 0 0» 和 «8 1 0»，一共 {{10}} 种。题2 规定的顺序就是外层 z、内层 y。

## s6 | ⑥ 逻辑配对 | ⑥ | 逻辑配对：把对手当成字符来枚举
甲队 A、B、C 对乙队 X、Y、Z。用三个 char 变量 a、b、c 表示 A、B、C 各自的对手，每个从 `'X'` 枚举到 `'Z'`：
::code
for (a = 'X'; a <= 'Z'; a++)
  for (b = 'X'; b <= 'Z'; b++)
    for (c = 'X'; c <= 'Z'; c++)
      if (a != b && b != c && a != c       // 三个对手互不相同
          && 题目给的条件)
        printf("A--%c B--%c C--%c\n", a, b, c);
::
字符能 `++`、能比大小，因为它就是整数（环02 细1）。题目条件「A 说他不和 X 比，C 说他不和 X、Z 比」写成 `a != 'X' && c != 'X' && c != 'Z'`，结果是 {{A--Z B--X C--Y}}。

## s7 | ⑦ 解方程 vs 枚举 | ⑦ | 能解方程就解，不能就枚举
鸡兔同笼 35 头 94 腿，解方程：兔 = (94 − 2×35) / 2 = {{12}}，鸡 = {{23}}。

枚举也行：鸡 x 从 0 试到 35，兔就是 35 − x，检查 `2*x + 4*(35 - x) == 94`。枚举的好处是**无解的情况自动处理**：腿数是奇数、或者腿比头的 2 倍还少，一个都试不出来，打印「无解」就行。

## s8 | ⑧ 估算循环次数 | ⑧ | 估一下要循环多少次
两层各 100 次就是 1 万次，三层就是 100 万次，计算机一眨眼就跑完。考试不用担心快慢，但题目说「尽量减少循环层数」时，要写成 ② 那样。

# p2 | 循环和 switch 的坑 | 每一节最后附了真题的问法，灰色小字是出处。

## d1 | 细1 for 的省略写法 | 细1 | for 的三个表达式都能省，分号不能省
`for (表达式1; 表达式2; 表达式3)`，三个都可以不写，但**两个分号必须在**。表达式里还可以用逗号写好几件事。
::calc
i = 1; s = 0; for (; i <= 3;) { s += i; i++; } ‖ s = ‖ 6
for (x = 0, y = 0; y != 99 && x < 4; x++) ‖ 循环 ‖ 4 次
i = 4; for (printf("%d", i); i < 2; i++) printf("%d", i); ‖ 输出 ‖ 4 ‖ 表达式 1 照样执行一次，条件一开始就假
::
`for (;;)` 是死循环：条件不写就当永远为真，要靠 break 出来。
::exam
上表第 2 行，循环执行几次 => 4 次 @ 配-5-28、配-5-29
上表第 3 行的输出 => 4 @ 配-5-35
`for (;;) { s += i; i++; if (i <= 10) break; }` 和另外三个求和写法哪里不同 => 只加了一次就 break @ 配-5-34
::

## d2 | 细2 嵌套循环次数 | 细2 | 嵌套循环：内层每一轮都从头开始
外层每走一步，内层就**从头完整跑一遍**。
::calc
for (i = 1; i <= 4; i++) for (j = 1; j <= 3; j++) ‖ 内层共 ‖ 12 次 ‖ 4 × 3
for (i = 1; i <= 4; i++) for (j = i; j <= 4; j++) ‖ 内层共 ‖ 10 次 ‖ 4 + 3 + 2 + 1
::
::code
for (i = 3; i >= 1; i--) {
    for (j = 1; j <= 2; j++) printf("%d", i + j);
    printf(" ");
}
::
输出 {{45 34 23}}。
::exam
上面那段的输出 => 45 34 23 @ 配-5-50
九九乘法表上三角 @ 配-5-56
内层 break 之后外层还继续吗 => 继续，break 只跳出内层 @ 配-5-51
::

## d3 | 细3 条件里带 ++ | 细3 | 条件里带自增自减
条件里有 `a++`，就是**先拿旧值判断，再加 1**。最后那次判断失败，`++` 也照样执行了。a = −2、b = 0：
::calc
while (a++) ++b; ‖ → ‖ a = 1，b = 2 ‖ 判 −2、−1 为真，判 0 为假，判完 a 还是加成了 1
do { ++b; } while (a++); ‖ → ‖ a = 1，b = 3 ‖ do-while 先做一次
::
`x = 23; do { printf("%d", x--); } while (!x);` 只输出 {{23}}：x-- 之后 x 是 22，`!22` 是 0。
::exam
上表第 1 行 => 1,2 @ 配-5-12
上表第 2 行 => 1,3 @ 配-5-18
`do { … x--; } while (!x);`（x = 23）输出 => 只有 23 @ 配-5-19
`while (!--x)` 跑几次 @ 配-5-21
`do { while (--y) x++; } while (y--);` => 5,-1 @ 配-5-26
do-while 条件里带自减 @ 川师卷2016-17 一-4
::

## d4 | 细4 读字符的循环 | 细4 | 读字符的循环，括号一个都不能少
::calc
while ((ch = getchar()) != 'N') ‖  ‖ 对 ‖ 先读字符赋给 ch，再拿 ch 和 'N' 比
while (ch = getchar() != 'N') ‖  ‖ 错 ‖ != 比 = 先算，ch 拿到的是比较结果 0 或 1
while (getchar() != '\n'); ‖  ‖ 对 ‖ 吃掉这一行剩下的字符，直到回车
while ((ch = getchar()) != "\n") ‖  ‖ 错 ‖ 双引号是字符串，不能和字符比
::
统计一行有几个字符：`n = 0; while ((ch = getchar()) != '\n') n++;`

反复读整数直到读不进来，写 `while (scanf("%d", &x) == 1)`。~~`while (scanf("%d", &x))`~~ 不稳：读到文件结束时 scanf 返回 −1，−1 也是真。
::exam
`while (ch = getchar() != 'N')` 的问题 => ch 得到的是 0 或 1 @ 配-5-2
`while (getchar() != '\n');` 的作用 => 跳过这一行剩下的字符 @ 配-5-5
`!= "\n"` 写法 => 错，字符不能和字符串比 @ 配-5-43
`do { c = getchar(); putchar(c); } while (c != '#');` 输入 «abcdefg##» => abcdefg# @ 配-5-24
输入到 # 结束，统计字符 @ A-2012-4
::

## d5 | 细5 switch 合法吗 | 细5 | switch 的合法写法
三条规矩：括号里是**整数**（字符也是整数）；case 后面是**常量**；case 的值**不能重复**。
::calc
switch (a + b) ‖  ‖ 合法
switch (ch) ‖  ‖ 合法 ‖ 字符就是整数
case 'A': 、case 1 + 2: ‖  ‖ 合法 ‖ 常量表达式
switch (x)（x 是 double） ‖  ‖ 不合法
case c:（c 是变量） ‖  ‖ 不合法
case 1, 2: 、case 1..5: ‖  ‖ 不合法
两个 case 3: ‖  ‖ 不合法 ‖ 重复
switch (a + b); { … } ‖  ‖ 不合法 ‖ 多了分号，后面的 {} 不属于 switch 了
::
> 还有个阴的：`case1:` 少了空格，就成了一个叫 case1 的标号，能编译，但永远匹配不到。
::exam
选出合法的 switch => A（B 用了未定义的变量，C 是 float，D 多了分号） @ 真选5·武科大2019
判断哪个 switch 正确 @ 配-4-59、配-4-60、配-4-61
switch 合法性 @ 川师卷2018-19 一-8
::

## d6 | 细6 switch 穿透 | 细6 | 穿透：没有 break 就一直往下走
匹配到一个 case 以后，**一直往下执行**，直到遇到 break 或者 switch 结束，下面的 case 标签拦不住它。
::code
switch (n) {
    case 1: printf("one ");
    case 2: printf("two ");
    case 3: printf("three "); break;
    default: printf("other ");
}
::
n = 1 输出 {{one two three}}，n = 2 输出 {{two three}}，n = 4 输出 {{other}}。

default 写在哪都行，只有**一个 case 都没匹配上**时才进去，进去以后同样会往下穿透：
::code
s = 0;
for (n = 0; n < 4; n++)
    switch (n) {
        default: s += 4;
        case 1: s += 1; break;
        case 2: s += 2; break;
        case 3: s += 3;
    }
::
s = {{11}}：n = 0 走 default，加 4 再穿透加 1；n = 1、2、3 各加 1、2、3。

> 多个 case 共用一段：`case 1: case 3: case 5: printf("奇数"); break;`。成绩分档常写 `switch (score / 10)`。
::exam
option = 'W' 的 switch 输出 => Welcome Bye @ 真选32·北航2018
上面第二段 => 11 @ 配-4-73
穿透累加 @ 配-4-65
switch 里一定要用 break 吗 => 不一定 @ 配-4-58
::

## d7 | 细7 循环里的 switch | 细7 | 循环里的 switch：break 归 switch，continue 归循环
`break` 只跳出 switch，循环照样继续；`continue` 不属于 switch，它直接作用于外面的循环。
::code
i = 1; k = 0;
for (; i < 6;) {
    switch (i % 3) {
        case 0: k++;
        case 1: k++; break;      // 跳出 switch，接着执行 i += 1
        case 2: k++; continue;   // 跳过 i += 1，直接下一轮
    }
    i += 1;
}
::
i = 1 正常走完变成 2。i = 2 时进 case 2，`continue` 跳过了 `i += 1`，i 永远是 2，这是个 {{死循环}}。
::exam
上面这段的结果 => 死循环，i 一直是 2 @ 配-4-67
::

## d8 | 细8 嵌套 switch | 细8 | 嵌套 switch：内层 break 只跳出内层
::code
x = 1; y = 0; a = b = 0;
switch (x) {
    case 1:
        switch (y) {
            case 0: a++; break;
            case 1: b++; break;
        }
    case 2: a++; b++; break;    // 外层 case 1 没写 break，穿透到这里
    case 3: a++; b++;
}
::
a = {{2}}，b = {{1}}：内层 case 0 让 a 加 1，break 只出了内层；外层接着穿透到 case 2，a、b 各加 1。
::exam
上面这段 => a = 2，b = 1 @ 配-4-71
::

## d9 | 细9 三种循环互改 | 细9 | 三种循环可以互相改写
::code
for (i = 1; i <= 10; i++) s += i;
i = 1; while (i <= 10) { s += i; i++; }        // 更新放在循环体最后
i = 1; do { s += i; i++; } while (i <= 10);    // 条件第一次就为真时才等价
::
do-while 至少做一次，所以只有条件第一次就成立时，它才和另外两种完全等价。
::exam
把 for 改写成 while @ 真综1·华南理工2018
do-while 和 while 能不能互相改写 => 能 @ 配-5-27
::

## d10 | 细10 看出死循环 | 细10 | 一眼看出死循环
三种常见情况：条件永远为真、更新语句没了、while 后面多了分号。
::calc
n = 10; while (n); { n--; } ‖ → ‖ 死循环 ‖ 分号让 while 管的是空语句，n 永远是 10
for (i = 0, k = -1; k = 1; k++) ‖ → ‖ 死循环 ‖ 条件是赋值 k = 1，永远为真
for (k = 2; k == 0; ) ‖ → ‖ 一次都不执行 ‖ 第一次判断就是假
n = 0; do { ++n; } while (n <= 0); ‖ → ‖ 跑 1 次 ‖ 不是死循环
::
::exam
上表第 1 行 => 死循环 @ 配-5-33
上表第 2 行 => 死循环 @ 配-5-31
上表第 3 行 => 一次都不执行 @ 配-5-32
::
