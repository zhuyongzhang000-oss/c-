# p1 | 编程题怎么写 | 拆位只有两个动作：`% 10` 取出个位，`/ 10` 去掉个位。

## gu | 骨架 | | 通用骨架
::code
int m = n;                 // 先复制一份，n 后面还要用
while (m > 0) {
    d = m % 10;            // 取个位
    // 用 d：计数、求和、判断，或者拼数 r = r * 10 + d
    m /= 10;               // 去个位
}
::

## s1 | ① % 10 和 / 10 | ① | 拆位：% 10 取个位，/ 10 去个位
拆 472，每轮先取个位、再去个位：
::table
m | m % 10 | m / 10
472 | 2 | 47
47 | 7 | 4
4 | 4 | 0
::
m 变成 0，循环结束。注意数字是**从个位往高位**出来的：2、7、4。要按原来的顺序用，就得先存起来再倒着用（见 ⑦）。

## s2 | ② 三位数直接拆 | ② | 三位数可以直接拆
位数固定时不用循环，一句一位。x = 153：
::calc
x / 100 ‖ 百位 ‖ 1
x / 10 % 10 ‖ 十位 ‖ 5 ‖ 先去掉个位，再取个位
x % 10 ‖ 个位 ‖ 3
x % 10 / 10 ‖ → ‖ 0 ‖ 顺序反了：个位 3 再除以 10 就没了
::
水仙花数就是判断 百位³ + 十位³ + 个位³ 是不是等于 x 本身。立方写 `d * d * d`，不要用 pow（见细10）。

## s3 | ③ 先复制 | ③ | 先复制一份再拆
拆位循环会把 m 一直除到 0。如果后面还要用原来的数（比如数完位数再去比较），一开始就要复制：
::code
int m = n, cnt = 0;
while (m > 0) { cnt++; m /= 10; }
// 循环结束：m 是 0，n 还是原来的数
::
n = 25 时，cnt = {{2}}，循环结束后 m = {{0}}，n = {{25}}。

## s4 | ④ n 是 0 | ④ | n 是 0 的时候
`while (m > 0)` 遇到 m = 0，**一次都不进去**。所以用上面的写法数 0 的位数，得 {{0}}，可 0 明明是 1 位数。

「0 有几位」「0 的二进制」这种情况要单独处理，或者改用 `do { … } while (m > 0);`，先做一次再判断。

## s5 | ⑤ 拼数 | ⑤ | 拼数：r = r * 10 + d
从个位往外取，同时往 r 后面接，数就倒过来了：
::code
r = 0;
while (m > 0) { r = r * 10 + m % 10; m /= 10; }
::
1230 倒过来拼成 {{321}}：末尾的 0 跑到最前面，就没了。

> 环08 的「数字串转整数」用的是同一个式子：`v = v * 10 + (s[i] - '0')`。

## s6 | ⑥ 取末 k 位 | ⑥ | 取末 k 位：用整数乘出 10 的 k 次方
同构数要比较「x 的平方的末几位」和 x。x 是两位数就要 `% 100`，一位数就 `% 10`。这个 100 用整数一路乘出来：
::code
int mod = 1, t = x;
while (t > 0) { mod *= 10; t /= 10; }   // x 有几位，mod 就乘几次 10
if (x * x % mod == x) …
::
x = 25 时 mod = {{100}}，625 % 100 = {{25}}，所以 25 是同构数。

~~`625 % pow(10, 2)`~~ 编译不过：pow 返回的是 double，`%` 两边必须是整数。

## s7 | ⑦ 除 2 取余，倒着输出 | ⑦ | 十转二：除 2 取余，倒着输出
和 ① 一模一样，只是把 10 换成 2。6 依次得到的余数是 {{0 1 1}}，倒过来 {{110}} 才是二进制。

所以余数要先存进数组，最后从后往前用。题3 要你把结果写成字符串，还有两个细节：

- 数字 d 变成字符要写 `'0' + d`：`'0' + 1` 是字符 {{'1'}}（细2）。
- 字符串最后**一定补 `'\0'`**，否则 printf 不知道在哪里停。测试会查这个。

## s8 | ⑧ 外层换数，内层重新复制 | ⑧ | 外层换一个数，内层要重新复制
统计 1 到 n 里数字 1 出现几次，外层枚举每个数，内层拆位：
::code
for (i = 1; i <= n; i++) {
    int t = i;              // 每换一个数都重新复制
    while (t > 0) { if (t % 10 == 1) total++; t /= 10; }
}
::
1 到 12：1、10、11、12 里一共有 {{5}} 个 1（11 算两个）。

如果直接拿 i 去拆，`i /= 10` 会把外层的循环变量改掉，循环就乱了。

# p2 | 字符和位运算的坑 | 每一节最后附了真题的问法，灰色小字是出处。

## d1 | 细1 字符就是小整数 | 细1 | 字符就是一个小整数
`char c = 'A';` 存进去的其实是 65（A 的 ASCII 码）。用 `%c` 打出来是 A，用 `%d` 打出来是 65。

三个码要背：`'A'` 是 {{65}}，`'a'` 是 {{97}}（小写比大写大 32），`'0'` 是 {{48}}。

`'0'`、`0`、`'\0'` 是三样东西：数字字符 0（值 48）、整数 0、空字符（值是 0，是字符串的结束标志）。所以 `'\0' == 0` {{为真}}，`'0' == 0` {{为假}}。
::calc
`char c = 'A' + 2;` 用 %c ‖ → ‖ C
同一个 c 用 %d ‖ → ‖ 67
::
::exam
c1 = 'A'、c2 = 'Y'，按 %d 输出 => 65,89 @ 配-3-46
c1 = 'A'、c2 = 'D'，`printf("%d,%d", c1, c2 - 2);` => 65,66 @ 配-3-58
`'\0' == 0` 和 `'0' == 0` => 前者真，后者假 @ 配-3-49
`char c = '\101';` 占几个字节 => 1 @ 配-3-35
::

## d2 | 细2 字符运算 | 细2 | 字符可以加减
既然字符是整数，就能加减。最常用的四个：
::calc
'g' - 32 ‖ → ‖ 'G' ‖ 小写变大写
'Q' + 32 ‖ → ‖ 'q' ‖ 大写变小写
'7' - '0' ‖ → ‖ 7 ‖ 数字字符变数值
'0' + 5 ‖ → ‖ '5' ‖ 数值变数字字符
'C' + '8' - '3' ‖ → ‖ 'H' ‖ '8' − '3' 是 5，C 往后数 5 个
('Z' - 'A' + 1) % 26 + 'A' ‖ → ‖ 'A' ‖ Z 的下一个绕回 A
::
判断大写：`c >= 'A' && c <= 'Z'`。~~`!(c >= 'A' || c <= 'Z')`~~ 是错的，这个条件对任何字符都是假。
::exam
`c1 = 'C' + '8' - '3';` 用 %c、`c2 = '9' - '0';` 用 %d => H 和 9 @ 配-3-48
`ch = 'Z'; ch = (ch - 'A' + 1) % 26 + 'A';` => A @ 配-3-47
判断 c 是大写字母的正确写法 => `c >= 'A' && c <= 'Z'` @ 配-3-44
大写转小写的填空 => `(ch >= 'A' && ch <= 'Z') ? (ch + 32) : ch` @ 真综2·华南理工2018
::

## d3 | 细3 字符常量合不合法 | 细3 | 单引号里只能放一个字符
单引号里**只能有一个字符**，或者一个转义序列（反斜杠开头的那种）。
::calc
'a'、'9'、'\n'、'\0' ‖  ‖ 合法
'\\'、'\'' ‖  ‖ 合法 ‖ 反斜杠、单引号本身要转义
'\101' ‖  ‖ 合法 ‖ 八进制 101，就是 'A'
'\x41' ‖  ‖ 合法 ‖ 十六进制 41，也是 'A'
'ab'、'C++' ‖  ‖ 不合法 ‖ 多个字符
'' ‖  ‖ 不合法 ‖ 空的
'\019'、'\018' ‖  ‖ 不合法 ‖ 八进制里没有 8、9
'\0x41'、'\X41'、'\c' ‖  ‖ 不合法 ‖ 没有这些转义写法
::
> 编译器对 'ab' 只给警告（值由编译器决定），但考试一律算不合法。
::exam
非法的字符常量 => '\019' @ 配-3-36
`'aa'` => 非法，编译出错 @ 配-3-39、配-3-43
合法的转义字符 => '\x41' @ 配-3-41
不是转义字符的 => '\c' @ 配-3-42
::

## d4 | 细4 转义字符 | 细4 | 转义字符算一个字符
常用的：`\n` 换行、`\t` 跳到下一个制表位、`\\` 反斜杠、`\'` 单引号、`\"` 双引号、`\0` 字符串结束。还有 `\ddd`（1–3 位八进制）和 `\xhh`（十六进制）。

不管写成几个符号，**一个转义序列只算一个字符**：
::calc
strlen("ab\n") ‖ → ‖ 3
strlen("\t\\\101") ‖ → ‖ 3 ‖ \t、\\、\101 各算一个
'\72' ‖ → ‖ ':' ‖ 八进制 72 = 58，是冒号
::
::exam
`char c = '\72';` 存了几个字符 => 1 个 @ 配-3-57
`'\"'` 和 `'\\'` 合法吗 => 都合法 @ 配-3-38
::

## d5 | 细5 "a" 和 'a' | 细5 | "a" 是两个字节，'a' 是一个
双引号是**字符串**，最后自动带一个 `'\0'`；单引号是**一个字符**。
::calc
sizeof("a") ‖ → ‖ 2 ‖ a 和 \0
sizeof("") ‖ → ‖ 1 ‖ 空串也有一个 \0
'' ‖ → ‖ 不合法 ‖ 空字符常量不存在
::
打印也要对上：~~`printf("%c", "a")`~~ 是错的（%c 要一个字符，给的是字符串），`printf("%s", "a")` 才能打出 a。
::exam
两个连续的双引号 `""` => 合法的字符串常量，占 1 字节 @ 配-3-33、配-3-34
能输出字符 a 的 => `printf("%s", "a")` @ 配-3-3
`printf("%c\n", "a");` 能输出 a 吗 => 不能 @ 配-3-62
`'a=0'` 是什么常量 => 既不是字符常量也不是字符串常量 @ 配-3-55
::

## d6 | 细6 %c 读到空格回车 | 细6 | %c 和 getchar：空格、回车也是字符
`getchar()` 读一个字符，**空格和回车也算**；`putchar(c)` 输出一个字符。`scanf` 的 `%c` 也一样，不跳过空白。（`%d` 会跳过空白，见环01 细11。）
::calc
`scanf("%c%c", &a, &b);` 输入 «A B» ‖ → ‖ a = 'A'，b = ' ' ‖ 空格被当成字符读走了
`scanf("%d%c", &n, &c);` 输入 «5⏎» ‖ → ‖ c = '\n'
scanf("%d %c", &n, &c); ‖ → ‖ 格式里的空格会跳过所有空白，再读字符
::
一个读程序的例子：
::code
scanf("%c%c", &a, &b);
c = getchar();
d = getchar();
printf("%c%c%c%c", a, b, c, d);
::
输入 «12⏎34⏎»：a = {{'1'}}，b = {{'2'}}，c = {{'\n'}}，d = {{'3'}}。所以输出是 12、换行、3。
::exam
上面这段 => 输出 12、换行、3 @ 配-3-12
`scanf("%c%c", &a, &b);` 想让 a = 'A'、b = 'B'，输入 => «AB»，中间什么都不能有 @ 配-3-17、配-3-18
`scanf("%d%c%d%c", &a1, &c1, &a2, &c2);` 输入 => «12a34b»（数字后面紧跟字母） @ 配-3-24、配-3-26
scanf 读字符 @ 川师卷2016-17 一-10
::

## d7 | 细7 %o 和 %x | 细7 | %o、%x：八进制和十六进制输出
`%o` 按八进制、`%x` 按十六进制输出，**不带前缀**；加 `#` 才带 0 和 0x。255：
::calc
%d ‖ → ‖ 255
%o ‖ → ‖ 377
%x ‖ → ‖ ff
%X ‖ → ‖ FF
%#o ‖ → ‖ 0377
%#x ‖ → ‖ 0xff
::
手算十进制转十六进制：1100 = 4×256 + 4×16 + 12，所以是 {{44C}}。
::exam
十六进制输出用 => %x @ 真选19·华南理工2018
1100 的十六进制 => 44C @ 真选16·华南理工2018
k = −17，`printf("%d,%o,%x", k, 1 - k, 1 - k);` => -17,22,12 @ 配-3-7
::

## d8 | 细8 位运算 | 细8 | 位运算：按二进制一位一位算
先把数写成二进制再算。12 = 1100，10 = 1010：
::calc
12 & 10 ‖ → ‖ 8 ‖ 与：两位都是 1 才是 1 → 1000
12 | 10 ‖ → ‖ 14 ‖ 或：有一个 1 就是 1 → 1110
12 ^ 10 ‖ → ‖ 6 ‖ 异或：两位不同才是 1 → 0110
12 << 1 ‖ → ‖ 24 ‖ 左移 1 位，相当于乘 2
12 >> 2 ‖ → ‖ 3 ‖ 右移 2 位，相当于除以 4
::
别把位运算和逻辑运算搞混：`13 & 5` 是 {{5}}，`13 && 5` 是 {{1}}。`!` 是逻辑运算符，不是位运算符。

优先级：算术 > 移位 > 关系 > `&` > `^` > `|` > `&&` > `||`。所以 `a / b & c` 是 `(a / b) & c`。

> 位运算在教材正文里只简单提到，但题库第 3 章有近 30 道，川师本科卷也考过，按手算掌握。
::exam
`a = 12; (a << 2) << 1` => 96 @ 配-3-77
`(5 << 2) | 1` => 21 @ 配-3-85
`10 ^ 3` => 9 @ 配-3-83
`d = 2 | 4; d &= 5;` 之后 d => 4 @ 配-3-88
`13 & 5` 和 `13 && 5` => 5 和 1 @ 配-3-76
让高 4 位取反、低 4 位不变，和 11110000 做什么运算 => ^ @ 配-3-72
不是位运算符的 => ! @ 配-3-70
`a / b & c` 怎么结合 => `(a / b) & c` @ 配-3-81
位或运算 @ 川师卷2019-20 一-2
::

## d9 | 细9 负数拆位 | 细9 | 负数拆位
回忆环01 细5：负数的 `/` 和 `%` 都往 0 的方向。`-472 % 10` 是 {{-2}}，`-472 / 10` 是 {{-47}}。

所以 `while (m > 0)` 遇到负数一次都不跑。题目没说一定是正数时，先 `if (m < 0) m = -m;` 再拆。

## d10 | 细10 pow 的坑 | 细10 | 用 pow 要小心
`pow(5, 3)` 返回的是 double 125.0，不是 int。所以：

- ~~`x % pow(10, 2)`~~ 编译不过（% 两边要整数）。
- 用它判断整数相等也不稳：小数在计算机里可能有误差。

拆位求立方和，写 `d * d * d` 最稳。
