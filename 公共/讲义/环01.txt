# p1 | 编程题怎么写 | 这一环 5 道题，长得不一样，骨架是同一个：

## gu | 骨架 | | 通用骨架
::code
double s = 0;               // 和从 0 开始（求积就从 1 开始）
double t = 第一项;
for (i = 1; i <= n; i++) {
    s += t;
    t = 下一项;              // 用这一项算出下一项
}
::
题目没说算几项、只说「直到某一项的绝对值小于 1e-5」，就把 for 换成 while：
::code
while (fabs(t) >= 1e-5) {
    s += t;
    t = 下一项;
}
::

## s1 | ① 1/2 等于 0 | ① | 1 / 2 等于 0
先看一段想算 e 的代码：
::code
double e = 1;
for (i = 1; i <= 5; i++)
    e += 1 / i;
::
e 最后是 {{2.0}}，离 2.718 差得远。

原因：`1 / i` 两边都是整数，C 就做整数除法，**小数部分直接扔掉**。i = 1 时得 1，之后 1/2、1/3… 全是 0。e 是 double 也没用，因为除法在赋值之前就已经算完了。
::calc
1 / 2 ‖ → ‖ 0
1.0 / 2 ‖ → ‖ 0.5
(double)1 / 2 ‖ → ‖ 0.5 ‖ 先把 1 变成 1.0，再除
(double)(1 / 2) ‖ → ‖ 0.0 ‖ 括号里已经整除成 0 了，再转也晚了
::
改法：写 `1.0 / i`。只要有一边是小数，就按小数除。

> 这一条是全书出现次数最多的坑，后面求平均分、算比例、算面积都会再碰到。

## s2 | ② 和从 0，积从 1 | ② | 和从 0 开始，积从 1 开始
积的初值写成 0，乘多少次都是 0。这个错不报错，只会让答案莫名其妙变成 0。

另一个坑是**干脆不写初值**：函数里定义的 `int s;` 不会自动是 0，里面是一个不确定的数（配-2-51 就考这个）。累加之前一定先 `s = 0`。

## s3 | ③ int 只到 21 亿 | ③ | int 只装得下 21 亿
`int` 最大是 2147483647。12! = 479001600 还装得下，13! = 6227020800 就超了。超了**不会报错**，只会得到一个错的数。

题2 也会遇到：a = 3、n = 10 时最后一项是 3333333333，约 33 亿，int 同样装不下。测试里就有 n = 10。

办法是换大一点的类型：`long long`（printf 用 `%lld`），或者 `double`。

## s4 | ④ 用上一项推下一项 | ④ | 用上一项推下一项
e 的级数第 i 项是 1/i!。笨办法是每一项都重新算一遍阶乘；更好的办法是注意到**第 i 项 = 第 i−1 项 ÷ i**，于是每轮只做一次除法：
::code
t = 1;  e = 1;
for (i = 1; i <= n; i++) {
    t = t / i;      // 1/(i-1)!  变成  1/i!
    e += t;
}
::
跑几轮看看：
::table
i | t | e
开始 | 1 | 1
1 | 1 | 2
2 | 0.5 | 2.5
3 | 0.166667 | 2.666667
4 | 0.041667 | 2.708333
… |  |
10 | 0.000000276 | 2.7182818011
::
别的数列也是同一招：把第 i 项和第 i−1 项写在一起，看差了什么。比如

- x, x²/2!, x³/3!, …：下一项是 {{`t = t * x / i;`}}
- 1, −1/2, 1/3, −1/4, …：多一个符号变量，每轮 {{`sign = -sign;`}}

题2（3, 33, 333…）和题4（cos 级数）的下一项留给你自己推。题4 提示：相邻两项差一个负号，还差一个 x²，分母多乘了两个数。

## s5 | ⑤ 两个量一起变 | ⑤ | 两个量一起变，先存旧值
题3 的数列 2/1, 3/2, 5/3, 8/5…，规律是：新分子 = 分子 + 分母，新分母 = **原来的**分子。很自然会写成左边这样：
::pair 直接写 | 先存旧值
a = a + b;
b = a;
---
old = a;
a = a + b;
b = old;
::
从 2/1 开始各走三轮。左边：{{3/3 → 6/6 → 12/12}}；右边：{{3/2 → 5/3 → 8/5}}。

左边错在第二句：`b = a` 用的是第一句改过以后的 a。两个量互相要用对方的旧值时，先把旧值存起来。

还有一处：算 a/b 这一项时，a、b 是整数，要写 `(double)a / b`，不然又回到第 ① 节。

## s6 | ⑥ 小数绝对值用 fabs | ⑥ | 小数的绝对值用 fabs
精度型循环的条件是 `fabs(t) >= 1e-5`，意思是「这一项还不够小，就继续加」。`1e-5` 就是 0.00001。

两个容易错的地方：

- ~~用了 `abs`~~。abs 是给整数用的，`abs(-0.001)` 得 {{0}}，循环一开始就停了。fabs 在 `<math.h>` 里。
- ~~忘了取绝对值~~，写成 `while (t >= 1e-5)`。cos 级数第二项就是负的，循环会提前停。

按这个写法，小于 1e-5 的那一项不会加进去，正好符合「末项绝对值小于 1e-5 为止」。

## s7 | ⑦ 闰年和每月天数 | ⑦ | 闰年和每月天数
闰年：能被 4 整除但不能被 100 整除，或者能被 400 整除。写成代码：
::code
int leap = (y % 4 == 0 && y % 100 != 0) || y % 400 == 0;
::
试一下：2000 年 {{是}}，1900 年 {{不是}}，2024 年 {{是}}，2023 年 {{不是}}。1900 最容易错：它能被 4 整除，但也能被 100 整除，又不能被 400 整除。

每月天数放进数组，下标 0 空着放个 0，这样 `days[3]` 就是 3 月，不用减 1：
::code
int days[13] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
::
闰年的 2 月是 `days[2] + leap`。

## s8 | ⑧ 考试写完整程序 | ⑧ | 考试要写完整程序
电脑上每题只写一个函数，考试却是手写整个程序。拿一道不是本环必做的题举例，求 1 + 1/2 + … + 1/n：
::code
#include <stdio.h>

int main(void)
{
    int n, i;
    double s = 0;

    scanf("%d", &n);           // 变量前面有 &
    for (i = 1; i <= n; i++)
        s += 1.0 / i;
    printf("%f\n", s);
    return 0;
}
::
格式符最容易混的是 double：**输入必须 `%lf`**，输出 `%f` 和 `%lf` 都行。long long 输入输出都是 `%lld`。

> 教材常写 `void main()`，考试不扣分；平时按标准写 `int main(void)` 加 `return 0;`。

## d2 | 细2 0 开头是八进制 | 细2 | 0 开头的数是八进制
这是最阴的一个：`011` 不是 11，而是八进制的 11，等于 {{9}}。`0x` 开头是十六进制，`0x13` 等于 {{19}}。

既然 0 开头是八进制，八进制里又只有 0–7，那么 ~~`08`、`0118`、`-028`~~ 都不合法。

还有几个常见的假常量：~~`1,234`~~（数里不能有逗号），~~`o115`~~（字母 o 开头，是个名字），~~`0b101`~~（二进制写法 C23 才有，考试按「不能写」）。`115L` 是合法的 long 型常量。
::exam
`int x = 011; printf("%d", ++x);` 输出 => 10 @ 配-2-46
`int x = 0x13; printf("%d", x + 1);` 输出 => 20 @ 配-2-49
`int x = 010, y = 10; printf("%d,%d", ++x, y--);` 输出 => 9,10 @ 配-2-109
C 源程序里不能直接表示的数制 => 二进制 @ 配-2-45

## d3 | 细3 e 的写法 | 细3 | 小数常量：e 两边的规矩
小数点两边可以省一边，`.5` 和 `3.` 都对。

科学计数法只记一句：**e 前面必须有数字，e 后面必须是整数**（可以带负号）。所以 `1e1`、`.1e0`、`2.E8`、`1.5e-3` 都合法；~~`1.5E2.0`~~ 和 ~~`4e1.5`~~ 不行（e 后是小数），~~`e3`~~ 不行（前面没数，成了一个名字），~~`2.7e`~~ 不行（后面没数）。

> 小数常量默认是 double；写成 `1.5f` 才是 float。
::exam
选出合法的实数 => .1e0 @ 配-2-56
哪个不能表示 10000 => 1.0E4.0 @ 配-2-61
::

## d4 | 细4 类型和字节数 | 细4 | 各类型占几个字节、能存多大
按 VC 环境记：char {{1}}，int {{4}}，float {{4}}，double {{8}}。

教材有些表是按老的 Turbo C 写的，int 占 2 字节（−32768 ～ 32767）。题目说了「VC++ 环境」就按 4。

整数类型还能加修饰：`short`（VC 下 2 字节，−32768 ～ 32767）、`long`（VC 下 4 字节）、`unsigned`（没有负数，同样的字节数能存的正数翻倍，`unsigned int` 最大 4294967295）。

`sizeof` 是运算符，不是函数。教材里的 C 没有 `bool`，**非 0 就是真，0 就是假**。
::exam
VC++2010 上 `sizeof(int)`、`sizeof(double)` => 4,8 @ 配-2-52

## d5 | 细5 负数的 / 和 % | 细5 | 负数的整除和取余
正数大家都会：`17 / 5` 是 3，`17 % 5` 是 2。负数才是考点：
::calc
-17 / 5 ‖ → ‖ -3 ‖ 往 0 的方向砍，不是 −4
-17 % 5 ‖ → ‖ -2 ‖ 余数跟被除数同号
17 % -5 ‖ → ‖ 2 ‖ 被除数 17 是正的
::
另外 ~~`%` 只能用在整数上~~，`7.5 % 2` 编译不过。

取某一位：x = 4567 时，百位 `x / 100 % 10` 是 {{5}}，十位 `x / 10 % 10` 是 {{6}}，个位 `x % 10` 是 {{7}}。环02 会大量用到。
::exam
运算对象必须是整数的运算符 => % @ 配-2-64、配-2-65
x 是大于 1 的奇数，`x % 2 == 0` 的值 => 0 @ 配-2-82
取三位数 x 的百位 => `x / 100 % 10` @ 配-2-69

## d6 | 细6 一步一步算类型 | 细6 | 混合运算：一步一步看类型
这类题不要整体看，**按运算顺序一步一步算**，每一步只看这一步的两个数：都是整数就整除，有小数就按小数算。最后赋给 int 或者 `(int)` 强转，都是**砍掉小数**，不是四舍五入。

先自己算，再点开：
::calc
int z = 0.9 + 12 / 8; ‖ z = ‖ 1 ‖ 12/8 先得 1，0.9 + 1 = 1.9，进 int 砍成 1
double d = 7 / 2; ‖ d = ‖ 3.0 ‖ 7/2 先得 3，再变 3.0
(int)1.99 * 3 ‖ → ‖ 3 ‖ 强转只管紧跟着的 1.99
(int)(1.99 * 3) ‖ → ‖ 5 ‖ 5.97 砍成 5
(int)-3.99 ‖ → ‖ -3 ‖ 也是往 0 砍
(int)((double)9 / 2) - 9 % 2 ‖ → ‖ 3 ‖ 4.5 砍成 4，9%2 是 1
3.6 - 5 / 2 + 1.2 + 5 % 2 ‖ → ‖ 3.8 ‖ 5/2 是 2，5%2 是 1
::
`'A' + 10 + 3.14` 的类型是 double：char 先变 int，碰到 3.14 再变 double。强转要写 `(int)x`，~~`int(x)`~~ 是 C++ 的写法，C 编译不过。
::exam
x = 12、y = 8，`z = 0.9 + x / y`（z 是 int），z => 1 @ 配-2-72
`(int)1.99 * 3` => 3 @ 配-2-84
`(int)((double)9 / 2) - 9 % 2` => 3 @ 配-2-73
`3.6 - 5 / 2 + 1.2 + 5 % 2` => 3.8 @ 配-2-75
`'A' + a + b`（a 是 int、b 是 double）的类型 => double @ 配-2-62
`i = f = l = d = 20 / 3;`（int、float、long、double）之后各是多少 => i、l 是 6，f、d 是 6.0 @ 真选37·中财2018
::

## d7 | 细7 赋值也有值 | 细7 | 赋值本身也有值
`a = b = c = 5;` 能这么写，是因为 `c = 5` 这个式子本身的值就是 5，再交给 b，再交给 a。`=` 从右往左算。

两个读程序常考的：
::calc
x = 10; x -= x + x; ‖ x = ‖ -10 ‖ 右边整体先算：10 − (10 + 10)
a = (b = 2) + 3; ‖ → ‖ a = 5，b = 2
::
判断合法时只看一件事：**等号左边是不是一个变量**。~~`a + 1 = a;`~~、~~`5 = a;`~~、~~`a = (b = 3) = 1;`~~ 左边都不是变量，都不行。`x = y == 5;` 是合法的：先算 `y == 5` 得 0 或 1，再赋给 x。

还有一个：~~`int a = b = c = 5;`~~ 在 b、c 没有事先定义时不合法，因为这一句只定义了 a。
::exam
`int a = b = 0;` 合法吗 => 不合法 @ 配-2-39
`x = 10; x -= x + x;` 之后 x => -10 @ 配-2-103
选出合法的赋值语句：看左边是不是变量、用到的变量定义了没有 @ 配-2-91、92、94、100
::

## d8 | 细8 i++ 和 ++i | 细8 | i++ 和 ++i
两个都会让 i 加 1。区别在于这个式子**交出来的值**：`i++` 交出加之前的 i，`++i` 交出加之后的 i。

依次执行：
::calc
i = 5; a = i++; ‖ → ‖ a = 5，i = 6
b = ++i; ‖ → ‖ i = 7，b = 7
i = 3; a = -i++; ‖ → ‖ a = -3，i = 4 ‖ 就是 −(i++)
::
单独一句 `i++;` 和 `++i;` 没区别。只能对变量用：~~`5++`~~、~~`(j + 1)++`~~ 编译不过。
::exam
k = 0 时，`++k`、`k += 1`、`k++`、`k + 1` 哪个的值和其他三个不同 => k++（它是 0，其余是 1） @ 配-2-107
四组语句里哪组输出的 n 和其他三组不同 => n = x++ 那组 @ 配-2-108
`-i++` 的值和 i 的变化，方法同上面第 3 行 @ 川师卷2018-19 一-5
::

## d9 | 细9 逗号 | 细9 | 逗号表达式
逗号把几个式子串起来，从左到右都执行，整个式子的值是最后一个。

考点在于 **`=` 比逗号先算**。看这句：
::code
x = y = 1;
z = x++, y++, ++y;
::
它其实是 `(z = x++), y++, ++y;`。所以 x = {{2}}，y = {{3}}，z = {{1}}。

想让 z 拿到整个逗号式子的值，必须加括号：`z = (x = 10, x + 5);` 得 z = {{15}}。
::exam
上面那段，输出 x, y, z => 2,3,1 @ 配-2-115
`z = (x, y)` 和 `(z = x, y)` 的区别 => 前者 z 得 y，后者 z 得 x @ 配-2-102
逗号表达式求值，方法同上 @ 川师卷2019-20 一-1
::

## d10 | 细10 printf 格式 | 细10 | printf 的宽度和小数位
`%5d` 占 5 格、靠右；`%-5d` 靠左；`%05d` 左边补 0；`%.2f` 保留 2 位（四舍五入）；`%8.3f` 一共占 8 格，小数点也算一格。数比宽度长，就原样全部输出。`%f` 不写位数默认 6 位小数。

下面用 · 表示空格：
::calc
printf("%5d", 42) ‖ → ‖ «···42»
printf("%-5d", 42) ‖ → ‖ «42···»
printf("%05d", 42) ‖ → ‖ «00042»
printf("%8.3f", 3.14159) ‖ → ‖ «···3.142»
printf("%e", 123.456) ‖ → ‖ «1.234560e+02»
printf("%%") ‖ → ‖ «%» ‖ 两个 % 打出一个
::
::exam
`printf("%d%8.6f", 12, 3.141593);` => «123.141593»（宽 8 刚好装下，中间没空格） @ 配-3-10
`printf("%4d,%o,%x", 10, 10, 10);` => «··10,12,a» @ 配-3-6
`printf("a=%%d,b=%%d", a, c);` => «a=%d,b=%d» @ 配-3-11
x = 2.12，哪种格式输出不完整 => %5.0f（只剩 2） @ 配-3-5
::

## d11 | 细11 scanf | 细11 | scanf：格式里写什么，就得敲什么
scanf 的格式串是一张「输入模板」。除了 `%d` 这些，里面写的其他字符都要原样敲进去：
::calc
scanf("%d%d", &a, &b); ‖ 敲 ‖ «3 4»（空格、回车都行）
scanf("%d,%d", &a, &b); ‖ 敲 ‖ «3,4»（逗号必须敲）
scanf("a=%d", &a); ‖ 敲 ‖ «a=3»
::
宽度会截断：`scanf("%2d%f", &a, &b);` 输入 «876 543.0»，a 只读两位得 {{87}}，剩下的 6 给了 b，b = {{6.0}}。

三个硬规矩：

- 变量前加 `&`，数组名不加。~~`scanf("%d", a);`~~ 常常能编译，运行时把数写到乱地址。
- double 输入**必须** `%lf`，float 用 `%f`。
- 格式里不能写精度，~~`scanf("%3.2f", &x);`~~ 是错的。
::exam
x 是 int、y 是字符数组、z 是 double，正确的输入语句 => `scanf("%d%s%lf", &x, y, &z);` @ 真选3·武科大2019
`scanf("%d;%d", &a, &b);` 要让 a = 3、b = 5，敲 => «3;5» @ 配-3-16
输入 «a=1,b=2,c=3»（b 是 float、c 是 double），格式串 => `"a=%d,b=%f,c=%lf"` @ 配-3-19
int、float、double 依次配 => %d %f %lf @ 配-3-28
::
> 字符的 `%c` 会把空格和回车也读进来，环02 讲。

## d12 | 细12 未定义行为 | 细12 | 一个变量在一句里被改两次
像 `i = i++ + 1;`、`a += a -= a * a;`、`printf("%d %d", i, i++);` 这样，同一个变量在一句里被改了两次，C 标准**没有规定结果**（叫未定义行为），换个编译器结果就可能不一样。自己写程序**绝对不要这样写**。

但题库和期末卷还是会出，并且按「从右往左一步一步赋值」给答案。考试遇到就按这个思路算：
::exam
`a = 12; a += a -= a * a;` 之后 a => -264 @ 配-2-104
`a = 3; a += a -= a * a;` 之后 a => -12 @ 川师卷2019-20 一-8
::
> 算法：先算右边的 `a -= a * a`，a = 3 − 9 = −6；再算 `a += a`，−6 + (−6) = −12。

## d13 | 细13 C 程序的结构 | 细13 | 一个 C 程序长什么样
教材第 1 章的选择题，围绕下面这几句话出：

- C 程序由**函数**组成，**有且只有一个 main**，程序**从 main 开始执行**，main 写在文件哪里都行。
- `#include`、`#define` 这种 `#` 开头的是**预处理命令**，在编译之前处理，末尾**不加分号**。
- 每条语句以分号结束，一行可以写好几条，一条也可以分几行写。
- 注释 `/* … */` 和 `//` 不参与编译；`/* */` 不能嵌套。
- C 语言**本身没有输入输出语句**，printf、scanf 是库函数。

判断一下：
::calc
main 必须写在程序最前面 ‖  ‖ 错 ‖ 位置随意，总是从 main 开始执行
`#include <stdio.h>;` ‖  ‖ 错 ‖ 预处理命令末尾不加分号
printf 是 C 的关键字 ‖  ‖ 错 ‖ 是库函数，在 stdio.h 里声明
一行只能写一条语句 ‖  ‖ 错
::
从源程序到运行要经过：编辑（`.c`）→ 编译（得到 `.obj`）→ 链接（得到 `.exe`）→ 运行。漏分号、括号不配对是**编译**时发现的；调用了只声明没写的函数，**链接**时报错；能运行但结果不对是**逻辑错误**，只能靠测试发现。
::exam

预处理命令的特点（# 开头、编译前处理、不加分号） @ 川师卷2022-23 一-3

## d14 | 细14 算法 | 细14 | 算法的五个特性和三种结构
教材第 2 章考的是概念，记住这两组就够：

**五个特性**：有穷性（步数有限，不能死循环）、确定性（每一步没有歧义）、有零个或多个输入、有一个或多个输出、有效性（每一步都能做到）。

最常考的是输入输出那两条：算法**可以没有输入**，但**必须有输出**。

**三种基本结构**：顺序、选择、循环。循环分当型（先判断再做，对应 `while`）和直到型（先做再判断，对应 `do-while`）。三种结构都是一个入口、一个出口。

**表示方法**：自然语言、流程图（起止框是圆角矩形、判断框是菱形、输入输出框是平行四边形、处理框是矩形）、N-S 图、伪代码、程序语言。

> 结构化程序设计的方法：自顶向下、逐步细化、模块化设计、结构化编码。
::exam
关于算法的叙述，错误的是 => 「一个正确的算法必须有输入」 @ 配-1-12
算法的五个特性里不包括 => 简洁性 @ 真选44·川大2017
::
