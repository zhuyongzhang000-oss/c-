# p1 | 编程题怎么写 | 指针版的题，算法和下标版一模一样，只是把 `a[i]` 换成 `*p`、把 `i++` 换成 `p++`。

## gu | 骨架 | | 通用骨架
::code
while (*s != '\0') {      // 读游标 s、写游标 t 同步走
    *t = *s;
    s++; t++;
}
*t = '\0';                // 别忘结束符
::

## s1 | ① 对象图 | ① | 先画对象图
`int a = 4, *p = &a;`：
::out
   a            p
 ┌───┐       ┌────┐
 │ 4 │ ◀──── │ &a │
 └───┘       └────┘
::
p 里存的是 a 的地址，`*p` 就是 a。执行 `*p = 7;` 之后，a 是 {{7}}，p 本身没变。

`&p` 是 p 自己的地址（指针变量也有地址），见细9。

## s2 | ② 指针遍历数组 | ② | 指针遍历数组：从 a 走到 a + n
::code
for (p = a; p < a + n; p++)
    s += *p;
::
`a + n` 是最后一个元素**后面那一格**（尾后）：可以拿来比较，不能用 `*` 去读。

int a[4] = {2, 4, 6, 8} 求和得 {{20}}，循环结束时 `p - a` = {{4}}。

再遍历一次，必须先 `p = a;` 复位，不然 p 从尾后开始，一次都不跑。

## s3 | ③ *p++ 三兄弟 | ③ | *p++、(*p)++、++*p：先加括号再算
单目运算符从右往左结合，所以 `*p++` 是 `*(p++)`。a = {10, 20, 30}，q = a，依次执行：
::calc
v = *q++; ‖ → ‖ v = 10，q 指向 a[1] ‖ 取原来指的值，然后 q 挪
(*q)++; ‖ → ‖ 数组变成 10 21 30 ‖ 改的是值，q 不动
w = ++*q; ‖ → ‖ w = 22，数组 10 22 30 ‖ 先让值加 1，再取
::
一句话：**括号里是谁，谁就变**。`*(p++)` 是 p 变；`(*p)++` 是 *p 变。

## s4 | ④ 子数组 | ④ | 子数组：传 a + k
把 `a + 2` 传给函数，函数里的 `p[0]` 就是 a[2]。int a[6] = {1, 2, 3, 4, 5, 6}，p = a + 2：p[0] = {{3}}，p[1] = {{4}}，后面还剩 {{4}} 个，长度也要跟着减。

## s5 | ⑤ 指针复制字符串 | ⑤ | 指针复制字符串：两个游标同步走
就是骨架那几行。复制完一定补 `*t = '\0';`（环08 ⑤）。

熟练以后会看到简写：`while ((*t++ = *s++) != '\0');`，连 `'\0'` 一起复制了。读得懂就行，自己写用骨架那种更不容易错。

比较两个字符串（题2）也是同步走：`while (*p1 == *p2 && *p1 != '\0') { p1++; p2++; }`，最后返回 `*p1 - *p2`。

## s6 | ⑥ 第 k 个是 s + k − 1 | ⑥ | 「第 k 个字符」是 s + k − 1
「第几个」从 1 数，下标从 0 数，差一个。"computer" 从第 4 个字符起是 {{puter}}，起点是 `s + k - 1`；写成 `s + k` 会得到 {{uter}}，少了一个。

还要先检查 k 合不合法：1 ≤ k ≤ 长度。

## s7 | ⑦ 两头往中间走 | ⑦ | 指针版逆序：两头往中间走
::code
l = a; r = a + n - 1;
while (l < r) {
    t = *l; *l = *r; *r = t;
    l++; r--;
}
::
`l < r` 就是环06 细8 的「只走一半」。{1, 2, 3, 4, 5} 逆序后是 {{5 4 3 2 1}}。

n = 0 时要先返回，不然 `a + n - 1` 就是 `a - 1`，越界。

## s8 | ⑧ 循环右移 | ⑧ | 循环右移 m 位
最后 m 个移到最前面。m 比 n 大时先 `m = m % n`：右移 8 位和右移 {{2}} 位（n = 6）一样。

用辅助数组最直接：第 i 个放到第 `(i + m) % n` 个位置。{1, 2, 3, 4, 5, 6} 右移 2 位得 {{5 6 1 2 3 4}}。

不用辅助数组也行：重复 m 次「把最后一个存起来，其余整体往后挪一格，再把它放到最前面」。往后挪时**从右往左**，和环06 ⑤ 的插入一样。

# p2 | 指针的各种写法 | 这一部分的题都是「看写法判断意思」。拿不准就画对象图。

## d1 | 细1 * 只管一个名字 | 细1 | 定义时的 * 只管紧跟它的名字
`int *p, q;` 里 p 是指针，**q 是普通 int**。

`int *p = &a;` 等于 `int *p; p = &a;`，~~不是 `*p = &a;`~~：定义时的 `*` 只是说明 p 是指针。

指针只能存同类型变量的地址；不能直接赋整数（~~`p = 5;`~~），只有 0 或 NULL 可以。
::exam
`char c1, c2, *c3, c4[40];` 是合法的定义吗 => 是 @ 配-6-3
指针赋值的合法性 @ 真选20·华南理工2018、真选25·华南理工2018
::

## d2 | 细2 四种等价写法 | 细2 | 数组元素的四种写法
p = a 时，这四个是同一个元素：
::code
a[i]    *(a + i)    p[i]    *(p + i)
::
`&a[i]` 和 `a + i` 是同一个地址。int a[5] = {11, 12, 13, 14, 15}：
::calc
*(a + 3) ‖ → ‖ 14
p = &a[1]; 之后 p[2] ‖ → ‖ 14 ‖ 从 p 开始数
*p + 3 ‖ → ‖ 15 ‖ 先取 *p（12），再加 3
*(p + 3) ‖ → ‖ 15 ‖ 先挪 3 格，再取
::
::exam
`int a[10] = {1, …, 10}, *p = a;` 值为 9 的 => `*(p + 8)` @ 真选41·中财2018
`k = m; *(k + 2)` @ 配-6-16
`s = a;` 之后 `*(s + 3)` 代表 => a[3] @ 配-6-19
`a[p - a]`、`p[i]`、`*(&a[i])` 都是哪个元素 @ 配-6-28
::

## d3 | 细3 数组名不能 ++ | 细3 | 数组名不能 ++，指针变量可以
`int a[5], *p = a;`：`p++` 对；~~`a++`~~、~~`a = p`~~ 错。数组名是常量地址（回顾里那道）。

> 函数形参 `int a[]` 其实是指针变量，所以在函数里 `a++` 是可以的。

## d4 | 细4 指针相减 | 细4 | 两个指针相减：差几个元素
同一个数组里的两个指针相减，得到的是**相隔几个元素**，不是字节数：
::calc
int a[10]; p1 = a; p2 = &a[5]; p2 - p1 ‖ → ‖ 5
double d[10]; q1 = d; q2 = d + 5; q2 - q1 ‖ → ‖ 5 ‖ 也是 5，不是 40
::
::exam
`p1 = a; p2 = &a[5]; p2 - p1` => 5 @ 配-6-15
::

## d5 | 细5 字符数组和字符指针 | 细5 | 字符数组 vs 字符指针
::pair 字符数组 | 字符指针
char a[] = "cat";
a[0] = 'b';      // 可以：a 有自己的格子
a = "dog";       // 不行：数组名不能赋值
---
char *p = "cat";
p = "dog";       // 可以：改的是指向
p[0] = 'b';      // 不行：改字符串常量
::
左边执行完 a 是 {{bat}}，`sizeof(a)` 是 {{4}}。

两个未定义行为要认得：
- `char *s = "cat"; s[0] = 'b';`：改字符串常量，多数环境直接崩溃。
- `char *s; scanf("%s", s);`：s 没有指向任何存储。
::exam
能正确进行字符串操作的，D 选项 `char *s; scanf("%s", s);` => 错 @ 真选9·武科大2019
`char *ch; ch = "abc";` => 对 @ 配-6-100
::

## d6 | 细6 行指针 | 细6 | 二维数组和行指针
二维数组名 a 是**行指针**：`a + 1` 跳过一整行；`a[1] + 2` 只跳两个元素。
::code
a[i][j]  ==  *(*(a + i) + j)  ==  *(a[i] + j)
::
`int a[3][4] = {{0, 1}, {2, 4}, {5, 8}};`：`*(*(a + 1) + 1)` 是 {{4}}，`*(a[2] + 1)` 是 {{8}}。

`int (*p)[4] = a;` 定义的就是行指针，p 指向「含 4 个 int 的一行」，`p[1][1]` 也是 4。~~`int *p = a;`~~ 类型不对，要写 `int *p = a[0];` 或 `&a[0][0]`。
::exam
`int (*p)[4] = w;` 值为 4 的 => `p[1][1]` @ 真选26·华南理工2018
`int (*pt)[3]` 是什么 => 指向每行 3 个整数的二维数组的指针 @ 配-6-73
`int *p; p = a;`（a 是二维数组）=> 错 @ 配-6-74
::

## d7 | 细7 指针数组和数组指针 | 细7 | int *p[4] 和 int (*p)[4]：看括号
::calc
int *p[4]; ‖ → ‖ 指针数组 ‖ p 是数组，4 个元素，每个都是 int*
int (*p)[4]; ‖ → ‖ 数组指针（行指针） ‖ p 是一个指针，指向含 4 个 int 的数组
::
`[]` 比 `*` 结合得紧，所以没括号时 p 先和 [4] 结合，是数组；有括号时 p 先和 * 结合，是指针。

指针数组常用来存一组字符串：`char *name[3] = {"May", "April", "June"};`，`name[1]` 是 {{April}}，`name[1][0]` 是 {{'A'}}。排序时交换指针就行，不用 strcpy。
::exam
`int *p[4]` 的含义 @ 配-6-11、配-6-72
::

## d8 | 细8 函数指针 | 细8 | 函数指针 vs 返回指针的函数：也看括号
::calc
int (*f)(int, int); ‖ → ‖ 函数指针 ‖ f 指向一个「收两个 int、返回 int」的函数
int *f(int, int); ‖ → ‖ 返回指针的函数 ‖ f 是函数，返回 int*
::
::code
int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }
int (*f)(int, int);
f = add;  printf("%d ", f(2, 3));
f = sub;  printf("%d", (*f)(2, 3));
::
输出 {{5 -1}}。`f = add;` 不加括号，~~`f = add(2, 3);`~~ 是把返回值赋给指针，错。

函数返回局部变量的地址（`return &x;`）：函数结束 x 就没了，调用者再用是未定义行为。
::exam
`int (*ptr)()` 的含义 => 指向返回 int 的函数的指针 @ 川师卷
::

## d9 | 细9 二级指针和 argv | 细9 | 二级指针；main 的参数
想在函数里改调用者的**指针变量**，就要传指针的地址，形参是 `int **`。道理和环09 ⑤ 一样，只是被改的东西本身是个指针。
::code
int x = 7, *p = &x, **pp = &p;
::
`**pp` 是 {{7}}，`*pp` 就是 p。

main 也可以有参数：`int main(int argc, char *argv[])`。argc 是参数个数（**含程序名**），argv[0] 是程序名，argv[1] 起是参数。

命令行 `sample January February March`：argc 是 {{4}}，argv[2] 是 "February"。`*++argv[2]` 先让 argv[2] 挪到 "ebruary"，再取第一个字符，输出 {{e}}。
::exam
上面那个命令，`printf("%c", *++argv[2]);` => e @ 真选36·北航2018
::

## d10 | 细10 malloc 和 free | 细10 | 动态内存：malloc、判 NULL、free
::code
#include <stdlib.h>
int *p = (int *)malloc(n * sizeof(int));
if (p == NULL) { 申请失败; }
… 像数组一样用 p[i] …
free(p);
p = NULL;
::
- malloc 返回的是 `void *`（「不指定类型的指针」），要转成需要的类型。
- malloc 来的内容**不会自动清零**；`calloc` 会清零。
- 申请失败返回 NULL，用之前要判断。
- 用完 free，而且只能 free 一次。`realloc` 的结果先放进临时指针，成功了再替换。

环12 的链表就要用 malloc 一个一个申请结点。
