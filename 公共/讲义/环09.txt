# p1 | 编程题怎么写 | 一个结果用 return 交回来；要改调用者的变量、或者要带回好几个结果，就用指针参数。

## gu | 骨架 | | 通用骨架
::code
double area(double top, double bottom, double h);   // 原型：写在 main 前面

int main(void)
{
    double a, b, h;
    scanf("%lf%lf%lf", &a, &b, &h);
    printf("%.2f\n", area(a, b, h));                // 调用
    return 0;
}

double area(double top, double bottom, double h)     // 定义
{
    return (top + bottom) * h / 2;
}
::

## s1 | ① 函数三件套 | ① | 原型、定义、调用
- **原型**（声明）：`double area(double top, double bottom, double h);`，以分号结尾，写在 main 前面，告诉编译器「有这么个函数，要三个 double，给回一个 double」。
- **定义**：真正的函数体。
- **调用**：`area(3, 5, 4)`，得 {{16.00}}。

三处的返回类型、参数个数和类型要一致。把整个定义写在 main 前面，就可以不写原型。

## s2 | ② return 和 printf | ② | return 交回结果；printf 只是打印
`return` 把结果交回调用的地方，调用处可以接住、再用；函数里 `printf` 只是打到屏幕上，调用处拿不到。

题目说「编写函数求……」，一般都是 return 结果，由 main 输出。

返回值会按**函数的返回类型**转换：int 函数里 `return 2.9;`，调用处得到 {{2}}。

## s3 | ③ 值传递 | ③ | 函数拿到的是复制品
::code
int bump(int x) { x++; return x; }

a = 3;
bump(a);          // a 还是几？
a = bump(a);      // 现在呢？
::
`bump(a);` 之后 a 是 {{3}}：函数改的是自己的 x，x 是 a 的复制品；返回值也没人接。`a = bump(a);` 之后 a 是 {{4}}。

这就是「单向值传递」：实参的值复制给形参，形参怎么改都传不回去。

## s4 | ④ 指针入门 | ④ | 指针：存地址的变量
`&x` 是 x 的地址。`int *p = &x;` 让 p 存着 x 的地址，之后 `*p` 就是 x 本身：
::code
int x = 5, *p = &x;
*p = 8;           // 等于 x = 8
::
执行后 x 是 {{8}}。

两个 `*` 意思不一样：定义时 `int *p` 的 `*` 表示「p 是指针」；用的时候 `*p` 表示「p 指着的那个变量」。

## s5 | ⑤ 传地址才能改 | ⑤ | 想改调用者的变量：传地址进去
::pair 传值（换不了） | 传地址（能换）
void swap(int a, int b)
{
    int t = a; a = b; b = t;
}
// 调用：swap(x, y);
---
void swap(int *a, int *b)
{
    int t = *a; *a = *b; *b = t;
}
// 调用：swap(&x, &y);
::
x = 1、y = 2：左边调用后 x、y 是 {{1、2}}，换的是复制品；右边是 {{2、1}}。

右边两个容易错的地方：
- 中间变量是普通的 `int t`，~~不是 `int *t`~~。`int *t; *t = *a;` 里 t 没指向任何地方，往那里写是未定义行为。
- 要交换的是 `*a` 和 `*b`（两个变量的值），~~不是 a 和 b~~（那只是换了函数里的两个地址副本）。

## s6 | ⑥ 多个结果用指针带回 | ⑥ | 多个结果：用指针参数带回
return 只能交回一个值。题3 要同时求最大值和最小值，就让 main 把两个变量的地址传进来：
::code
void maxmin(int arr[], int *pmax, int *pmin, int n);

// main 里：
maxmin(arr, &mx, &mn, 10);
printf("max=%d,min=%d\n", mx, mn);
::
函数里对 `*pmax`、`*pmin` 赋值，就是对 main 的 mx、mn 赋值。函数体留给你写，思路和环06 找最小值一样。

## s7 | ⑦ 数组参数和长度 | ⑦ | 数组参数：能改元素；要改长度就再传 &n
数组传进去的是地址，函数能直接改元素（环06 细6）。但长度 n 是个普通 int，要在函数里让它加 1，就得传 `&n`：
::code
void append(int a[], int *n, int x)
{
    a[*n] = x;
    (*n)++;            // 不能写 *n++，见细10
}
// main 里：append(a, &n, 9);
::
a = {1, 2, 3}、n = 3，调用后 n 是 {{4}}，a[3] 是 {{9}}。

## s8 | ⑧ 二维数组参数 | ⑧ | 二维数组参数：列数必须写
::code
int total(int m[][3], int rows)
{
    int i, j, s = 0;
    for (i = 0; i < rows; i++)
        for (j = 0; j < 3; j++) s += m[i][j];
    return s;
}
::
`int m[2][3] = {{1, 2, 3}, {4, 5, 6}};`，`total(m, 2)` 得 {{21}}。

形参的列数必须写，而且要和实参一样（环07 细6）。

# p2 | 函数和变量的规矩 | 这部分以概念选择题为主。每一节最后附了真题的问法。

## d1 | 细1 不能嵌套定义 | 细1 | 函数不能嵌套定义，可以嵌套调用
~~在一个函数里面再定义一个函数~~，不行；在一个函数里**调用**另一个函数，可以，`fun(fun(x))` 也可以。

不写返回类型，教材按 int 处理（C99 起标准取消了这个规定，编译器会报错或警告，平时要写全）。
::exam
函数返回值类型缺省时是 => int @ 真选18·华南理工2018
函数里能不能定义另一个函数 => 不能 @ 配-2-9
`fun(fun(x))` 合法吗 => 合法，是嵌套调用 @ 配-2-7
::

## d2 | 细2 先声明后调用 | 细2 | 先声明，后调用
定义写在 main 后面时，main 前面要有原型。原型可以省掉形参名：`double area(double, double, double);` 也对。

void 函数没有返回值，~~`t = fun(…);`~~ 这样接是编译错误。
::exam
`void fun(char ch, float x[]); float a[5];` 正确的调用 => 题面存疑，见下 @ 真选11·武科大2019
::
::fix
真选11 原书答案 B 写成 `t = fun('D', a);`，可 fun 是 void，这样赋值是错的，题面应是 `fun('D', a);`。其他选项：A `fun("a", a[])` 实参写法错；C `'65'` 不是合法字符；D `a[5]` 是一个元素不是数组。
::

## d3 | 细3 形参是局部变量 | 细3 | 形参是函数自己的局部变量
实参可以是常量、变量、表达式；形参只能是变量。形参在调用时才分配空间，调用结束就释放。

「实参和形参之间是单向值传递」：传指针也一样，只是这次复制过去的值是一个地址。
::exam
「在一个函数的复合语句中定义的变量，在本函数范围内有效」 => 错，只在那个复合语句里有效 @ 真选22·华南理工2018
::

## d4 | 细4 作用域 | 细4 | 作用域：变量在哪里能用
局部变量只在定义它的 `{}` 里有效。同名时，**里面的盖住外面的**：
::code
int g = 9;                     // 全局
int read_g(void) { return g; }

int main(void)
{
    int g = 1;                 // 盖住了全局 g
    { int g = 2; printf("%d ", g); }
    printf("%d ", g);
    printf("%d", read_g());
}
::
输出 {{2 1 9}}：内层块的 g 是 2；出了内层块是 main 的 1；read_g 里没有局部 g，用的是全局的 9。

不同函数可以用同名变量，互不相干。全局变量从定义的位置往后，所有函数都能用。

## d5 | 细5 static 局部变量 | 细5 | static 局部变量：只初始化一次
::pair 普通局部变量 | static 局部变量
int plain(void)
{
    int n = 0;
    n++;
    return n;
}
---
int counter(void)
{
    static int n = 0;
    n++;
    return n;
}
::
各调用三次：plain 得 {{1 1 1}}，counter 得 {{1 2 3}}。static 变量只在第一次初始化，函数结束后值还留着。

static 局部变量的**作用域**还是只在函数里，只是**寿命**变长了。局部 static 和全局变量不初始化时自动为 0。
::code
void ff(void)
{
    int c = 9;
    static int a = 1, b = 4;
    if (b == 4) { a += c; b++; }
    else        { a += c; b--; }
    printf("a=%d,b=%d  ", a, b);
}
// main 里：ff(); ff();
::
输出 {{a=10,b=5  a=19,b=4}}。
::exam
上面这段 => a=10,b=5 a=19,b=4 @ 真选23·华南理工2018
static 填空 @ 川师卷2018-19 三-2
::

## d6 | 细6 存储类别 | 细6 | 存储类别：auto、static、register、extern
- **auto**：局部变量和形参默认都是 auto。
- **static**：见细5。全局变量前加 static，只能在本文件里用。
- **register**：建议放进寄存器；不能对它取地址 `&`。
- **extern**：声明「这个变量在别处定义了」，不再分配空间。

函数也分内外：函数前加 `static` 是**内部函数**，只能本文件调用；不加就是**外部函数**，别的文件也能调用。
::exam
形参的缺省存储类别 => auto @ 真选46·川大2017
::

## d7 | 细7 实参的计算顺序 | 细7 | 一句里调用好几次：顺序没规定
::code
printf("%d %d %d", counter(), counter(), counter());
::
可能输出 3 2 1，也可能输出 1 2 3：C 标准**没规定**实参先算哪个（未指定行为）。读程序题遇到要指出「顺序不确定」；自己写程序就拆成几句。

## d8 | 细8 实参类型要对上 | 细8 | 调用时类型要对上
要指针就给地址，要数组就给数组名：
::calc
int func(int *p); y = func(&x); ‖  ‖ 对
func(x); ‖  ‖ 错 ‖ 要地址给了整数
void sort(int a[][3], int n); sort(a, 3); ‖  ‖ 对 ‖ a 是 int a[3][3]
::
::exam
`int func(int *p);` 正确的调用 => `y = func(&x);` @ 真选13·武科大2019
`int a[3][3]; sort(a, 3);` 对应的声明 => `void sort(int a[][3], int n);` @ 真选12·武科大2019
`fun(int *p) { return *p; }` 返回的是 => p 所指存储单元里的值 @ 真选45·川大2017
::

## d9 | 细9 & 和 * | 细9 | & 和 * 是一对
`&x` 取地址，`*p` 取指向的值，`*&x` 就是 x。
::calc
int *p, m = 5, n = 0; p = &n; *p = m; ‖ → ‖ n = 5 ‖ 等于 n = m
p = &n; scanf("%d", p); ‖  ‖ 对 ‖ p 本身就是地址，不再加 &
scanf("%d", n); ‖  ‖ 错 ‖ 要地址给了整数
p = n; ‖  ‖ 错 ‖ 整数不能给指针
int *p, *s; s = &p; ‖  ‖ 错 ‖ &p 是「指针的地址」，类型不对
::
::exam
正确的程序段 => `p = &n; *p = n;` @ 真选20·华南理工2018
`int *p, *s, c;` 里 `s = &p;` => 错 @ 真选25·华南理工2018
::

## d10 | 细10 *n++ 和 (*n)++ | 细10 | *n++ 不是 (*n)++
`*q++` 等于 `*(q++)`：取 q 原来指着的值，然后 **q 自己**往后挪。`(*q)++` 才是让 q 指着的那个变量加 1。
::code
int a[3] = {10, 20, 30}, *q = a, v;
v = *q++;          // ①
v = (*q)++;        // ②
::
① 之后 v = {{10}}，q 指向 {{20}}；② 之后 v = {{20}}，a[1] 变成 {{21}}。

所以题4 里让长度加 1，要写 `(*n)++`、`++*n` 或 `*n = *n + 1`。写 ~~`*n++`~~ 是让指针 n 挪走了，长度没变，测试会专门提示这个错。

> 指针的更多写法在环11。
