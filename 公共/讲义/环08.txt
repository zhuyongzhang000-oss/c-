@intro C 没有「字符串类型」，字符串就是一个字符数组，最后放一个 `'\0'` 作结束标志。这一句话想通了，这一环的题和坑就都好理解了：所有循环都是「走到 `'\0'` 为止」，所有手写的结果都要「最后补一个 `'\0'`」。

== recall
`'7' - '0'` 的值 => 7 @ 环02 细2
`sizeof("a")` => 2（a 和 '\0'） @ 环02 细5
`int a[10];` 的下标范围 => 0 到 9 @ 环06 细3
两个数组能不能写 `a = b;` 整体赋值 => 不能，数组名是常量 @ 环06 细4
`r = r * 10 + d` 能把 1230 拼成 => 321 @ 环02 ⑤
==

# p1 | 编程题怎么写 | 字符串题的循环条件都是 `s[i] != '\0'`，不需要知道长度。

## gu | 骨架 | | 通用骨架
::code
for (i = 0; s[i] != '\0'; i++) {    // 走到结束符为止
    处理 s[i];
}
// 写一个新字符串时：i 负责读，k 负责写，最后 t[k] = '\0';
::

## s1 | ① 以 '\0' 结尾的字符数组 | ① | 字符串 = 以 '\0' 结尾的字符数组
`char s[] = "cat";` 在内存里是这样：
::table
下标 | 0 | 1 | 2 | 3
内容 | 'c' | 'a' | 't' | '\0'
::
4 个格子，最后一个是自动加上的 `'\0'`。所以：
::code
for (i = 0; s[i] != '\0'; i++) ;     // 循环结束时 i 就是长度
::
循环结束时 i = {{3}}，这就是手写的 strlen。

## s2 | ② 逆序输出 | ② | 逆序输出：从 len − 1 往回打
最后一个字符的下标是 `len - 1`：
::code
len = strlen(s);
for (i = len - 1; i >= 0; i--) putchar(s[i]);
::
"abcde" 输出 {{edcba}}。从 `len` 开始就会先打出那个 `'\0'`。

只是输出的话不用改数组；题目要「把字符串本身倒过来」，才用环06 细8 的「只走一半交换」。

## s3 | ③ 回文 | ③ | 回文：第 i 个和倒数第 i 个比
第 i 个和第 `len - 1 - i` 个比，只走前一半，有一对不同就不是：
::code
ok = 1;
for (i = 0; i < len / 2; i++)
    if (s[i] != s[len - 1 - i]) { ok = 0; break; }
::
"level" {{是}}回文，"abba" {{是}}，"abca" {{不是}}。

空串和只有一个字符的串：循环一次都不跑，ok 保持 1，都算回文。

## s4 | ④ 数字串转整数 | ④ | 数字串转整数：v = v × 10 + 这一位
和环02 ⑤ 的拼数是同一个式子，只是这一位要从字符变成数字（减 `'0'`）：
::table
i | s[i] | s[i] − '0' | v
0 | '4' | 4 | 4
1 | '0' | 0 | 40
2 | '6' | 6 | 406
::
~~忘了减 `'0'`~~，写成 `v = v * 10 + s[i]`，加进去的是 ASCII 码 52、48、54，结果完全不对。

## s5 | ⑤ 手写连接 | ⑤ | 不用库函数连接：先走到末尾，再抄，最后补 '\0'
::code
i = 0;
while (dest[i] != '\0') i++;            // i 停在 dest 的 '\0' 上
for (j = 0; src[j] != '\0'; j++)
    dest[i++] = src[j];
dest[i] = '\0';                          // 最容易漏
::
"code" 接上 "block" 得 {{codeblock}}。dest 至少要 4 + 5 + 1 = {{10}} 格。

常见错：写成 `dest[i] = src[i]`，两个数组用同一个下标，src 是从它的第 4 个字符开始抄的。所以读和写要**两个下标**。

## s6 | ⑥ 手写比较 | ⑥ | 手写比较：找第一对不同的字符
两个串一起走，直到某一对不同、或者走到结尾：
::code
i = 0;
while (s1[i] == s2[i] && s1[i] != '\0') i++;
return s1[i] - s2[i];
::
::calc
"And" 和 "Aid" ‖ → ‖ 5 ‖ 第 2 个不同：'n' − 'i'
"A" 和 "C" ‖ → ‖ -2
"ab" 和 "abc" ‖ → ‖ -99 ‖ 走到 '\0' 和 'c' 才不同，短的小
::
返回值只看正负：正数 s1 大，负数 s1 小，0 相等。

## s7 | ⑦ 字符分类统计 | ⑦ | 字符分类：字母、数字、空格、其他
::code
if ((c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z')) letter++;
else if (c >= '0' && c <= '9') digit++;
else if (c == ' ') space++;
else other++;
::
"Hi 2u! A9"：字母 {{4}}，数字 {{2}}，空格 {{2}}，其他 {{1}}。

## s8 | ⑧ 数单词 | ⑧ | 数单词：记住「现在在不在单词里」
用一个标志 `in`：碰到空格就 `in = 0`；碰到非空格、而且之前不在单词里，就是新单词开始了：
::code
in = 0; count = 0;
for (i = 0; s[i] != '\0'; i++) {
    if (s[i] == ' ') in = 0;
    else if (in == 0) { in = 1; count++; }
}
::
"␣␣hi␣␣go␣"（␣ 是空格）有 {{2}} 个单词。

~~数空格再加 1~~ 是错的：开头的空格、结尾的空格、连续的空格都会多算。

# p2 | 字符数组和字符串函数的坑 | 每一节最后附了真题的问法，灰色小字是出处。

## d1 | 细1 sizeof 和 strlen | 细1 | sizeof 和 strlen 不一样
`sizeof` 是这个数组**占几个字节**（含 `'\0'`，也含没用到的格子）；`strlen` 是**数到 `'\0'` 之前**有几个字符。
::calc
char a[] = "0123"; ‖ → ‖ sizeof 5，strlen 4
char b[] = {'0', '1', '2', '3'}; ‖ → ‖ sizeof 4 ‖ 没有 '\0'，不是字符串
char c[10] = "hi"; ‖ → ‖ sizeof 10，strlen 2
char d[] = "ab\n\\\101"; ‖ → ‖ sizeof 6，strlen 5 ‖ 转义算 1 个（环02 细4）
strlen("ab\0cd") ‖ → ‖ 2 ‖ 遇到第一个 '\0' 就停
::
::exam
`s1 = "0123"` 和 `s2 = {'0','1','2','3'}` 哪个长 => s1 长（多一个 '\0'） @ 配-6-98
`char str[] = "\0";` 合法吗 => 合法 @ 配-6-97
数组、字符串的定义和长度 @ 川师卷2018-19 二-1、二-2
同上 @ 川师卷2019-20 二-2、二-4
::

## d2 | 细2 初始化 | 细2 | 初始化：双引号自动带 '\0'
::calc
char s[] = "abc"; ‖ → ‖ 4 个字节，是字符串
char s[] = {'a','b','c'}; ‖ → ‖ 3 个字节，不是字符串 ‖ %s 输出会一直往后找 '\0'
char s[3] = "abc"; ‖ → ‖ 合法，但正好装满，没有 '\0'
char s[3] = "abcd"; ‖ → ‖ 编译错 ‖ 初值太长
char s[10] = {"abc"}; ‖ → ‖ 和 = "abc" 一样
char s[2] = {"A", "B"}; ‖ → ‖ 编译错 ‖ 花括号里放了两个字符串
::
::exam
能正确进行字符串操作的 => `char a[10] = {'A','B','C','D','\0'};` @ 真选9·武科大2019
哪个字符数组初始化合法 @ 配-6-99、配-6-100
`""` 是正确的字符串常量吗 => 是 @ 配-6-96
::

## d3 | 细3 不能用 = 赋值 | 细3 | 字符数组不能用 = 赋值
又是环06 细4：数组名是常量。所以：
::calc
char s[10]; s = "abcd"; ‖ → ‖ 编译错
strcpy(s, "abcd"); ‖ → ‖ 对
char *p; p = "abcd"; ‖ → ‖ 对 ‖ p 是指针变量，让它指向这个字符串（环11）
::
定义时 `char s[10] = "abcd";` 是**初始化**，可以；定义之后再 `=` 就是**赋值**，不行。二维字符数组交换一行，也要用 strcpy（细9）。
::exam
`char s[10]; s = "abcd";` => 编译不通过 @ 真选38·中财2018
::

## d4 | 细4 %s、gets、puts | 细4 | %s 读到空格就停
::calc
scanf("%s", s); 输入 «hello world» ‖ → ‖ s 只得到 hello ‖ %s 读到空白就停
gets(s); ‖ → ‖ 读一整行，含空格，不含回车 ‖ 教材写法，C11 已删除
fgets(s, 20, stdin); ‖ → ‖ 最多读 19 个，回车也读进来 ‖ 平时用这个
printf("%s", s + 2); ‖ → ‖ 从第 3 个字符开始输出
puts(s); ‖ → ‖ 输出后自动换行
::
`char s[] = "hello";` 时 `printf("%s", s + 2)` 输出 {{llo}}。

`scanf("%s", s)` 里 s 是数组名，**不加 &**（环01 细11）。写成 `&s`，教材按错误算。
::exam
`scanf("name=%s", …)` 输入 «name=Lili Wang»，读到 => Lili @ 配-3-22
::

## d5 | 细5 字符串函数 | 细5 | 四个字符串函数
要 `#include <string.h>`：
::calc
strcpy(a, b) ‖ → ‖ 把 b 连同 '\0' 复制到 a，a 原来的被覆盖
strcat(a, b) ‖ → ‖ 把 b 接到 a 后面 ‖ a 要装得下：strlen(a) + strlen(b) + 1
strcmp(a, b) ‖ → ‖ a 小得负数，相等得 0，a 大得正数
strlen(a) ‖ → ‖ 不含 '\0' 的长度
::
`char a[20] = "ab";` 执行 `strcat(a, "xyz")` 后 a 是 {{abxyz}}，strlen 是 {{5}}。

strcmp 的结果**只保证正负**，不保证是 1 或 −1。判断相等写 `if (strcmp(a, b) == 0)`。`strcmp("A", "a")` 是 {{负数}}：大写字母的码比小写小（环02 细1）。

> `strlwr`、`strupr` 不是标准函数；标准的是 `<ctype.h>` 里的 `tolower`、`toupper`，一次改一个字符。

## d6 | 细6 == 比的是地址 | 细6 | 用 == 比较字符串，比的是地址
::code
char s1[] = "Hello", s2[] = "Hello";
if (s1 == s2) printf("Equal");
else printf("Unequal");
::
输出 {{Unequal}}：s1、s2 是两个数组，地址不同。比内容要用 `strcmp(s1, s2) == 0`。
::exam
上面这段 => Unequal @ 真选35·北航2018
能不能用关系运算符比较字符串大小 => 不能 @ 配-3-33
::

## d7 | 细7 字符串常量长度 | 细7 | 字符串常量的长度
转义字符算一个；`'\0'` 后面的不算：
::calc
strlen("\t\\abc\101") ‖ → ‖ 6 ‖ \t、\\、a、b、c、\101
sizeof("abc") ‖ → ‖ 4
::

## d8 | 细8 字符和数字互转 | 细8 | 字符和数字互转
::calc
'7' - '0' ‖ → ‖ 7
3 + '0' ‖ → ‖ '3'
toupper('q') ‖ → ‖ 'Q' ‖ 要 #include <ctype.h>
tolower('Q') ‖ → ‖ 'q'
::

## d9 | 细9 字符串排序 | 细9 | 多个字符串：二维字符数组 + strcpy
多个名字放在二维字符数组里，一行一个（环07 细9）。排序时比较用 strcmp，交换要用 strcpy 和一个临时数组：
::code
if (strcmp(name[k], name[k + 1]) > 0) {
    strcpy(t, name[k]);
    strcpy(name[k], name[k + 1]);
    strcpy(name[k + 1], t);
}
::
{"tom", "amy", "bob"} 排完是 {{amy bob tom}}。~~`name[0] = name[1];`~~ 不行，一行就是一个数组。

## d10 | 细10 越界和忘补 '\0' | 细10 | 装不下、忘补 '\0'：结果都不确定
- `char s[5]; strcpy(s, "hello");` 要 6 格只有 5 格，越界。
- 手工复制完忘了 `t[k] = '\0';`，printf 会一直往后打，后面跟一串乱码。

读程序题里遇到这种情况，要先指出是未定义行为，不写确定的输出。
